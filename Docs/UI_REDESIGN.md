# v0.5 UI 개편

도시를 가리던 상시 패널을 줄이고, 건설·운송 중에는 실제 지도를 넓게 볼 수 있게 하는 개편입니다. 게임 시뮬레이션과 v4 저장 형식은 유지합니다.

## 참고한 게임

- [Cities: Skylines 공식 사용자 설명서, UI 부분](https://cdn.akamai.steamstatic.com/steam/apps/255710/manuals/CitiesSkylines-UserManual_EN.pdf): 화면 가장자리의 도구 막대에서 도시 기능을 선택하고 필요한 패널을 여는 배치.
- [Factorio 공식 위키의 Quickbar](https://wiki.factorio.com/Quickbar): 하단의 짧은 도구 슬롯으로 빠르게 건설 도구에 접근하는 방식.

위 게임의 UI 구성 방식을 참고합니다. 프로젝트에 넣는 실제 이미지 자산과 라이선스는 [UI_ASSETS.md](UI_ASSETS.md)에 기록합니다.

## 화면 구성

- 상단: 작은 자원 수치, 시대·연구와 인구 정보.
- 하단: 건설 분류와 도시 기능, 시간 제어.
- 건설 목록: 분류 버튼을 누를 때 펼치고 도구를 선택하면 접습니다. 현재 도구와 취소·회전은 작은 막대로 표시합니다.
- 선택 정보: 건물·설비·주민을 고른 경우에만 나타나며 닫을 수 있습니다.
- 목표, 도시 통계, 영토 확장, 교역: 필요한 기능을 눌러서 확인합니다.
- 저장·불러오기·새 도시·도움말: 메뉴에서 접근합니다. 기존 단축키도 유지합니다.

모달 창은 월드 입력을 막고 닫으면 입력을 복원합니다. 모바일 뒤로 가기는 열린 창을 먼저 닫습니다. 아이콘에는 한국어 이름을 함께 표시해 의미를 확인할 수 있게 합니다.

## 검증 기준

1600×900 및 1280×720 Windows 실행에서 실제 UI 레이캐스트를 사용합니다. 기본 상태가 가로막는 면적은 화면의 20% 이하, 선택 정보가 열린 상태는 30% 이하를 목표로 합니다. 이 수치는 UI 배경 색이나 추정 면적 대신, 일정한 간격으로 화면을 샘플링해 월드 입력이 차단되는 비율로 측정합니다.

메뉴·건설·선택·교역·영토·연구 버튼을 실제 EventSystem 경로로 누르고, 기능 접근성과 중앙 지도 입력을 확인합니다. 결과와 캡처는 `Artifacts/CompactUiSmoke`에 기록하며, 최종 통과 여부는 [VERIFICATION.md](VERIFICATION.md)에 기록합니다. Android 실제 기기 시각 검사는 포함하지 않습니다.
