# RIVERWORKS 변경 기록

플레이 동작을 기준으로 정리한 변경 기록입니다. 검증 결과와 검증 범위는 [VERIFICATION.md](VERIFICATION.md)에 별도로 기록합니다.

## v0.6 — 일하는 로우폴리 주민과 단우 안내

- Quaternius 로우폴리 주민 4종과 청록색 단우 모델을 가져왔습니다. UAL1/UAL2 애니메이션을 연결해 걷기·수확·벌목·운반·대화·휴식을 표현하며, 독서·반죽·망치질·보일러 조작은 보조 동작으로 구분합니다.
- 작업·여가 건물 16종의 마당에서 실제 주민이 활동합니다. 건물마다 최대 두 명과 작업 도구를 보여주며, 확대하거나 선택하면 한글 활동 설명이 나타납니다. 더 가까운 확대도 지원합니다.
- 각 주민 모델을 하나의 스킨드 메시·공유 재질로 합치고, 화면 밖 모션 평가와 모델 캐시를 제한했습니다. 주민의 인구·출퇴근·생산·LLM 계획과 단우 추적 루트는 유지합니다.
- Feel 5.6.1의 실제 `MMF_Player`를 버튼·창·자원 변화와 건설·철거·증축·연구·시대 발전·도시 목표·물류 동작에 연결했습니다. 연속 효과는 풀링하며 `움직임 줄이기`는 카메라 흔들림과 큰 이동을 줄이되 상태 피드백은 유지합니다.
- 새 도시는 시청이 쿵 소리와 함께 내려앉고 카메라가 가까이 당겨졌다가 도시 전경으로 돌아오는 연출로 시작합니다.
- 마을 서기 단우를 기존 시민과 같은 3D 모델·실제 도로 경로를 쓰는 주민으로 추가했습니다. 단우는 안내할 장소까지 걷고 카메라가 따라가며, 수동 카메라 조작은 추적을 해제하고 `단우 보기`로 다시 추적할 수 있습니다. 대화창의 별도 초상화는 사용하지 않습니다.
- 새 도시의 기본 흐름을 직접 수행하며 배우는 11단계 튜토리얼과, 성장 상태에 맞춰 한 번씩 열리는 19개 후속 기능 안내를 추가했습니다. 튜토리얼은 건설·연구·저장을 대신하지 않고 실제 플레이 결과를 확인하며 진행 상태와 읽은 안내를 도시 저장에 보존합니다.
- 모든 플랫폼의 기본 UI 글꼴을 Galmuri11 도트 한글 폰트로 바꿨습니다. 번들 글꼴을 우선 로드하고 동적 아틀라스에 포인트 필터링을 적용합니다.
- 선택형 주민 AI의 Unity 클라이언트와 Node.js OpenRouter 게이트웨이를 구현했습니다. 모델이 제안한 주민 방문 계획은 허용된 목적지, 도시 세대와 실제 도로 경로를 다시 검사하며, 실패하거나 기능을 끄면 기존 규칙 기반 일과를 계속 사용합니다. 제공자 키는 게이트웨이에만 두고 주민 생각과 짧은 기억은 실행 세션에만 유지합니다.
- Windows 빌드에서 Feel, 시청 도착, 단우 튜토리얼·후속 안내, Galmuri11과 주민 AI `MOCK_CONTRACT` 흐름을 검사했습니다. OpenRouter API 키가 입력되지 않아 실제 모델 호출은 검증하지 않았습니다.
- 공개 GitHub 소스 저장소와 Windows Release 패키징 절차, 코어·게이트웨이 자동 검사를 추가했습니다. 이번 릴리스는 Windows용이며 v0.6 Android APK와 실제 기기는 미검증입니다.

## v0.5 — 도시를 넓게 보는 UI

- 상시 표시하던 큰 좌우 패널을 없애고, 상단 자원 바와 하단 도구 막대 중심으로 바꿨습니다.
- 건설 목록은 분류를 누를 때 펼쳐지고 도구를 선택하면 접힙니다. 건물·설비·주민을 선택했을 때만 정보가 열리며 닫을 수 있습니다.
- 목표, 현황, 영토, 교역, 저장·불러오기·새 도시를 필요할 때 여는 창으로 정리했습니다. 교역에는 PC·모바일 모두 구매·판매 버튼이 있습니다.
- Cities: Skylines와 Factorio의 UI 구성 방식을 참고하고 공식 Kenney CC0 패널·버튼·아이콘을 적용했습니다. 출처와 원문 라이선스를 포함합니다.
- 작은 모바일 조작 버튼을 44픽셀 이상으로 보정하고, 뒤로 가기는 현재 창을 먼저 닫도록 했습니다. 주민 선택 시 이전 설비 정보가 남던 문제도 고쳤습니다.
- 같은 도시의 물류 규칙과 v4 저장 호환성은 유지합니다.

## v0.4 — 도시 안의 공장과 실제 물류

- 주택·도로·주민이 있는 같은 도시 땅에 공장 설비를 건설합니다. 도시 한 필지를 2×2 미세 칸으로 나누어 벨트·투입기·기계를 연결하며, 별도 공장 화면과 연습장 전환은 제거했습니다.
- 농장·벌목장 같은 도시 생산 건물에 투입기를 붙이면 생산물이 건물의 출고 버퍼에 쌓이고, 실제로 집어 벨트와 기계에 전달합니다. 완제품은 도로에 연결된 도시 창고·시장·시청에 도착할 때 도시 재고에 반영됩니다.
- 도시 가공 건물에도 투입기로 원료를 전달할 수 있습니다. 운송이 막히면 유한 버퍼가 차면서 생산이 멈추고, 도시 재고에 중복으로 더해지지 않습니다.
- 소유 영토·강·건물 점유를 함께 검사합니다. 채굴기는 자연 바위에 설치하며, 작은 운송 설비는 도로 위에 설치해 주민과 같은 공간을 사용합니다. 전력 인입기와 반출 부두에는 도시 도로 연결이 필요합니다.
- 도시 HUD에 설비·물류 탭, 방향·제조법·필터·재고 투입·검사기를 통합했습니다. Windows와 Android 모두 하나의 도시 카메라를 사용합니다.
- v4 저장은 도시와 이동 중 물류를 함께 보존합니다. 기존 v3의 분리된 공장은 원본을 보관하고 건설비 및 남은 물자를 한 번 전량 돌려준 뒤, 같은 도시에 재설계할 수 있도록 이전합니다. v1·v2 도시도 진행 상황을 유지하며 변환합니다.
- Windows x64와 Android ARM64 APK를 생성했습니다. PC 실행 검사와 APK 구성·서명 검사를 완료했으며 실제 Android 기기 동작은 아직 검사하지 않았습니다.

### 18개 기술과 모바일 지원

- 연구 기술을 9개에서 18개로 확장했습니다. 기존의 시대 진행 축은 유지되며 `길드`가 르네상스, `증기력`이 산업 시대를 열고 `도시 계획`이 3단계 증축과 최종 도시 목표를 해금합니다.
- 도시 생산 연구로 `산림 경영`(벌목장 +25%), `관개`(농장 +20%), `석공술`(채석장 +25%), `교육`(서재 레벨당 일일 연구 +1), `금속 공정 효율`(광산·제련소 +20%)을 추가했습니다.
- 공장 연구로 `물류`(벨트 속도 +50%), `전기화`(전력 수요 -15%), `대량 생산`(기계 제작 속도 +25%), `자동화`(투입기 속도 +50%)를 추가했습니다.
- 기존 v2·v3 도시는 완료한 연구와 현재 시대를 유지하며, 새 연구 가지를 이어서 진행할 수 있습니다.

## v0.3 — 물리 공장과 Android 빌드 준비

- 도시와 분리된 24×16 공장 부지를 추가했습니다. 벨트, 투입기, 채굴기, 용광로, 조립기, 저장고, 반입·반출 부두, 전력 인입기, 전신주와 분배기로 실제 물자를 운반하고 가공할 수 있습니다.
- 실제 공장은 빈 부지에서 시작하고 도시의 기술, 건설 자원과 남는 전력을 사용합니다. 반입한 도시 재고와 반출한 완제품, 철거 시 회수한 물자는 같은 도시 경제에 반영됩니다.
- 비용이나 기술 제한 없이 도구 생산선을 고칠 수 있는 연습 공장을 추가했습니다. 연습 공장의 배치와 물자는 도시 저장 및 생산 실적에 반영되지 않습니다.
- 도시와 공장을 하나의 v3 저장에 기록합니다. v2 저장은 기존 도시·연구·시대를 그대로 유지한 채 빈 실제 공장을 추가해 v3로 변환됩니다. v1 저장은 기존 도시 진행을 보존하기 위해 산업 시대와 현재 전체 기술 카탈로그를 승계한 뒤 빈 실제 공장을 추가합니다. 호환성을 위해 저장 파일명 `city-v1.json`은 유지합니다.
- Android 8.0(API 26) 이상, ARM64, IL2CPP, 가로 화면용 설정과 APK·Gradle 프로젝트 빌드 자동화를 추가했습니다. 도시와 공장에 한 손가락 탭·이동, 두 손가락 이동·핀치 확대와 시스템 뒤로 가기 동작을 연결했습니다.
- Windows x64 빌드와 실제 도시 자원을 사용하는 공장 런타임 흐름을 검증했습니다. Android ARM64 APK 생성, 서명과 패키지 구성 검사도 완료했습니다. 실제 Android 기기 동작은 검사하지 않았습니다.

## v0.2 — 시대 발전과 살아 있는 주민

- 새 도시가 중세에서 시작해 9개 핵심 기술을 연구하고 르네상스와 산업 시대로 발전하도록 만들었습니다. 연구에는 지식, 코인, 선행 기술과 시간이 필요하며 서재와 학술원이 연구 속도를 높입니다.
- 시대와 연구에 따라 건물, 2·3단계 증축과 증기 동력소를 해금하고, 건물과 도로의 외형 및 산업 시대 물류 차량이 함께 바뀌도록 했습니다.
- 주민마다 이름, 집, 일자리와 시장·공원 목적지를 부여했습니다. 주민은 실제로 연결된 도로와 다리를 따라 출근하고 장을 본 뒤 귀가하며, 선택하면 현재 목적지를 확인할 수 있습니다.
- 빵이 부족할 때 곡물로 식사를 대신하는 초기 생존 흐름과 연구·도시 진행을 저장하는 v2 형식을 추가했습니다.

## v0.1 — 도시 건설 기반

- 21×21 타일을 7×7 지역 9개로 나눈 도시 보드와 중앙 시청 정착지를 만들었습니다. 인접 지역을 구매해 영토를 확장할 수 있습니다.
- 도로 연결, 건설·철거·증축, 주택과 생산 시설, 코인과 8종 물자, 생산 사슬, 교역, 세금·유지비, 인구·행복과 도시 목표를 구현했습니다.
- 강과 다리, 숲·암석 생산 조건, 건물 상태 진단, 절차적으로 생성한 건물·지형·효과음과 한국어 HUD를 추가했습니다.
- 자동 저장, 수동 저장, 원자적 파일 교체와 백업 복구를 포함한 v1 도시 저장을 추가했습니다.
