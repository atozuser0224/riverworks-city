# RIVERWORKS 변경 기록

플레이 동작을 기준으로 정리한 변경 기록입니다. 검증 결과와 검증 범위는 [VERIFICATION.md](VERIFICATION.md)에 별도로 기록합니다.

## v0.9.0 — 도시 프로젝트·3층 공장·조건 자동화

- 대형 도시 프로젝트 3종, 지상·2층·3층 공장과 조건식 자동화를 함께 구현했습니다.
- 대교, 중앙 발전소, 연구 단지의 대형 도시 프로젝트를 추가했습니다. 각 프로젝트는 시작 비용을 내고 세 단계의 자재를 수동 납품한 뒤 도시 날짜가 지나야 완공됩니다. 같은 종류는 도시에 하나만 둘 수 있으며 공사 중 연결이 끊기면 날짜 진행이 멈춥니다.
- 대교는 4×1 부지에서 수면을 가로지르고 완공 시 네 칸을 실제 도로로 바꿔 기존 경로 탐색과 연결 판정에 참여합니다. 중앙 발전소는 완공·도로 연결 후 하루에 석탄 2개를 한 번만 소비해 그날 도시 전력 80을 공급하고, 연구 단지는 연결 중 매일 연구 점수 10을 더합니다.
- 공장에 지상·2층·3층을 추가했습니다. 2×2 미세 칸 플랫폼은 도시 부지 한 칸을 덮고, 3층 플랫폼은 같은 위치의 2층 플랫폼이 있어야 하며 상층 설비의 전체 면적이 플랫폼으로 지지되어야 합니다.
- 아이템 리프트와 유체 라이저를 추가해 설비를 23종으로 확장했습니다. 두 장치는 같은 좌표의 인접 층에 송신·수신 끝점을 한 쌍으로 만들며, 철거와 내부 물자 회수도 쌍 전체에 원자적으로 적용됩니다. 새로 받은 화물은 같은 틱에 다음 구간으로 다시 이동하지 않습니다.
- 전력망은 층을 구분합니다. 같은 층의 전신주만 평면 연결되고, 정확히 같은 좌표에서 인접 층에 놓인 전신주 쌍만 수직으로 전력을 잇습니다. 채굴기·물/원유 펌프·부두·전력 인입구는 지상 전용입니다.
- 도시 재고 또는 설비 재고·화물을 측정해 `이상/이하`와 `참일 때 허용/참일 때 중지`를 조합하는 조건 자동화를 추가했습니다. 허용 규칙은 모두 만족해야 하고 중지 규칙은 하나라도 참이면 대상을 멈춥니다. 대상당 최대 4개, 공장 전체 최대 64개 규칙을 저장합니다.
- 대상에 첫 규칙을 저장할 때 제어 장치 1개로 컨트롤러를 한 번 설치합니다. 이후 규칙 수정·삭제는 다시 청구하지 않고 설비 철거 시 제어 장치를 회수합니다. 수동 `Paused`는 저장되고 규칙이 덮어쓰지 않으며, `AutomationBlocked`는 저장하지 않고 매 틱 다시 계산합니다.
- 저장 형식을 도시 v6·공장 v3으로 올렸습니다. v1~v4는 먼저 기존 규칙으로 엄격한 v5·38칸 상태까지 변환하고 그 결과를 다시 검증한 뒤 v6으로 올립니다. 기존 v5도 38칸 배열과 공장 v2, 확장 필드 부재를 변경 전에 검사하며, 기존 설비는 지상·링크 없음·컨트롤러 없음으로 이관하고 수동 일시정지는 보존합니다.
- 자원 38종, 제조법 37종, 기술 26종과 기존 주민·도시 경제는 유지합니다. 플랫폼, 링크, 자동화 규칙과 도시 프로젝트는 기존 저장에 빈 상태로 추가하며 자동 보상이나 컨트롤러를 부여하지 않습니다.
- v0.8 복합 산업을 포함한 v0.9 통합 Windows 네이티브 검사와 Windows x64 빌드를 완료했습니다. 세부 결과와 검증 경계는 [VERIFICATION.md](VERIFICATION.md)에 기록합니다.

## v0.8 — 복잡 산업 (v0.9.0에 통합)

- 자원 카탈로그를 통화 1종, 고체 30종, 유체 7종의 총 38종으로 확장했습니다. 기존 9종 경제와 주민 식량·도구 소비는 유지하며, 벨트·투입기·창고는 고체만 운반하고 유체는 리터 단위 전용 망을 사용합니다.
- 설비를 21종, 제조법을 37종으로 늘렸습니다. 구리·석탄·보크사이트·원유·물을 추출하고 주조소·정밀 가공대·정유소·화학 공장·제조기에서 강철 보·파이프·모터·회로·컴퓨터·배터리·제어 장치까지 생산할 수 있습니다.
- 제조 배치는 여러 입력을 함께 소비하고 여러 출력을 한 번에 생성합니다. 주산물과 부산물의 모든 출력 공간을 먼저 확인하므로 중유·실리카·회수 물 같은 부산물 출구가 막히면 원료를 쓰지 않고 공정 전체가 대기합니다.
- 파이프·분기점·탱크와 물·원유 펌프를 추가했습니다. 파이프는 방향이 있고 한 종류의 유체만 담으며, 기계의 회전된 입력·출력 포트와 정확히 맞을 때만 흐릅니다. 같은 틱의 유체는 한 구간만 이동하고 탱크는 240L, 파이프는 40L를 저장합니다.
- 석유화학, 플라스틱·고무 재생, 보크사이트→알루미나 용액→스크랩→알루미늄 회수, 회로·컴퓨터·배터리와 제어 장치 조립 사슬을 추가했습니다. 새 도시의 지정 매장지와 기존 도시를 위한 원료 교역 경로를 함께 둡니다.
- 기술은 26종, 직접 선행 연결은 35개가 됐습니다. 유체 처리·석유 정제·석유화학·전자공학·알루미늄 가공·에너지 저장·고급 제조·산업 제어가 기존 연구 지도에 이어집니다.
- 생산 설비에 일시정지와 50/100/150/200% 클록을 추가했습니다. 150%와 200%는 고급 제조가 필요하며 생산 속도는 클록 비율, 전력 수요는 클록 비율의 제곱으로 변합니다. 정지한 전력 노드는 전력을 중계하지 않습니다.
- 산업 도감에서 37개 제조법, 38개 자원, 요구 기술·설비·입출력·기본 분당 생산량과 현재 생산·반출 현황을 검색할 수 있습니다. 제어 장치 3개 반출은 경제를 바꾸지 않는 선택 목표로 표시합니다.
- 저장 형식을 도시 v5·공장 v2로 올렸습니다. v1~v4는 변경 전에 기존 9칸 배열과 옛 ID 범위를 엄격히 검사한 뒤 모든 도시·물류·활성/보관 공장 배열을 38칸으로 확장하고, 새 자원은 0으로 두며 일시정지 해제·100% 클록을 적용합니다. 잘못된 현재 형식은 자동으로 자르거나 고치지 않습니다.
- 코어 풀체인은 원료 장부에서 제조법별 배치를 순서대로 실행하고 각 단계 산출물을 다음 단계로 넘기는 경계입니다. 네이티브 검사용 세 예제는 석유화학, 알루미늄 회수, 제어 장치 조립이며 제어 장치 예제는 준비된 컴퓨터·모터·배터리·모듈 프레임·알루미늄 케이싱부터 시작하는 최종 조립 범위입니다.
- 새 펌프·탱크·정유·화학·가공 설비 모델은 산업 설비 표현만 확장하며 기존 주민 모델과 주민 동작을 바꾸지 않습니다.
- v0.8은 독립 공개 릴리스로 게시하지 않고 v0.9.0에 통합했습니다. 통합 Windows 네이티브 검사와 빌드 결과는 [VERIFICATION.md](VERIFICATION.md)를 따릅니다.

## v0.7.0 — 연결형 연구 트리

- 기존 18개 기술과 19개 선행 관계를 중세·르네상스·산업 시대에 걸친 연결형 지도로 표시합니다. 다중 선행 조건과 선택한 기술까지의 모든 경로를 선과 화살표로 확인합니다.
- 기술·효과·해금 검색, 연구 가능·미완료 필터, 지도 이동, 정수 100/200% 확대, 시대·현재 연구 바로가기와 클릭 가능한 작은 지도를 추가했습니다.
- 상세 패널에 실제 수치 효과, 도시 건물과 공장 설비 해금, 선행·후속 기술, 미완료 연구 순서와 누적 비용·기간을 표시합니다. 이미 진행 중인 연구의 비용을 중복 합산하지 않습니다.
- 검색 입력 중에는 게임 단축키가 끼어들지 않습니다. 연구 시작은 기존 시뮬레이션의 지식·코인·선행 조건 검사를 거치며 v4 저장 형식을 유지합니다.
- 네 가지 정확한 렌더 크기의 연구 지도 검사 1,081개와 기존 도시·UI·튜토리얼·물류·주민 검사를 통과했습니다.

## v0.6.2 — UI 다듬기

- 연구 창을 화면 안에서 크기가 조정되는 시대별 스크롤 레이아웃으로 바꾸고, 다른 모달도 공통 카드·딤·44×44 닫기 버튼과 화면 크기 제한을 사용하도록 통일했습니다.
- 단우 대사는 실제 글자 렌더 높이에 맞춰 페이지를 나눠 본문 잘림을 막았습니다. 건설 목록이나 활성 도구 막대가 열리면 대화창을 그 위로 올리고, 기본 버튼 외의 처음부터·건너뛰기·기능 목록·다음 기능·기능 팁은 더보기 메뉴에 모았습니다.
- 설비 구성 창은 현재 설비에 맞는 제조법만 빈칸 없이 배치하고, 필터·재고 투입을 격자로 정렬하며 활성 섹션 높이에 맞춰 카드 크기를 조정합니다. 주민 AI 상태의 같은 의미 문구가 두 번 표시되지 않도록 정리했습니다.
- `HudStyle`로 화면 색과 의미를 공유하고 선택·확인·위험 상태를 구분했습니다. Galmuri11 글자는 11px 본문과 22px 제목을 기본으로 쓰며 가짜 굵기를 없앴고, 데스크톱·모바일 Canvas 배율을 정수 단위로 맞추면서 44px 터치 영역과 안전 영역을 유지합니다.
- 하단의 `주거·생산·산업·도시·설비·물류` 여섯 탭은 유지했습니다. 목록은 내용 폭에 맞춰 스크롤되고, PC 호버와 모바일 길게 누르기로 설명·비용·잠금 사유를 볼 수 있으며 선택한 도구 막대에도 비용을 표시합니다.
- 교역 창에 보유 코인과 물자별 보유 재고를 표시하고, 코인이나 판매 재고가 부족하면 해당 버튼을 비활성화합니다. 인스펙터는 상태·생산·레벨·재고를 행으로 나누고 전력 관련 건물과 설비에만 전력 조건을 표시하며 문제 상태를 강조합니다.
- 별도 공장 화면 시절의 미사용 `FactoryHud` 코드를 제거하고 같은 도시 HUD의 설비 UI만 유지했습니다.
- Windows 실행 검사를 통과했습니다. UI 779개, 단우 2,465개, 주민 AI 로컬 계약 160개와 네 가지 정확한 렌더 크기를 확인했습니다. Android 실기기와 실제 외부 모델 호출은 이번 검증에 포함하지 않습니다.

## v0.6.1 — 가까운 줌 유지

- 수동 카메라와 Feel 카메라 연출의 최소·최대 줌 범위를 한 곳에서 관리합니다. 가까이 확대한 뒤 드래그하거나 다시 확대해도 자동으로 멀어지지 않습니다.
- 가까운 배율에서 이동·반복 확대·Feel 반응과 반응 종료까지 확인하는 실행 회귀 검사를 추가했습니다.

## v0.6 — 일하는 로우폴리 주민과 단우 안내

- Quaternius 로우폴리 주민 4종과 청록색 단우 모델을 가져왔습니다. UAL1/UAL2 애니메이션을 연결해 걷기·수확·벌목·운반·대화·휴식을 표현하며, 독서·반죽·망치질·보일러 조작은 보조 동작으로 구분합니다.
- 작업·여가 건물 16종의 마당에서 실제 주민이 활동합니다. 건물마다 최대 두 명과 작업 도구를 보여주며, 확대하거나 선택하면 한글 활동 설명이 나타납니다. 더 가까운 확대도 지원합니다.
- 각 주민 모델을 하나의 스킨드 메시·공유 재질로 합치고, 화면 밖 모션 평가와 모델 캐시를 제한했습니다. 주민의 인구·출퇴근·생산·LLM 계획과 단우 추적 루트는 유지합니다.
- Feel 5.6.1의 실제 `MMF_Player`를 버튼·창·자원 변화와 건설·철거·증축·연구·시대 발전·도시 목표·물류 동작에 연결했습니다. 연속 효과는 풀링하며 `움직임 줄이기`는 카메라 흔들림과 큰 이동을 줄이되 상태 피드백은 유지합니다.
- 새 도시는 시청이 쿵 소리와 함께 내려앉고 카메라가 가까이 당겨졌다가 도시 전경으로 돌아오는 연출로 시작합니다.
- 마을 서기 단우를 기존 시민과 같은 3D 모델·실제 도로 경로를 쓰는 주민으로 추가했습니다. 단우는 안내할 장소까지 걷고 카메라가 따라가며, 수동 카메라 조작은 추적을 해제하고 `단우 보기`로 다시 추적할 수 있습니다. 대화창의 별도 초상화는 사용하지 않습니다.
- 새 도시의 기본 흐름을 직접 수행하며 배우는 11단계 튜토리얼과, 성장 상태에 맞춰 한 번씩 열리는 19개 후속 기능 안내를 추가했습니다. 튜토리얼은 건설·연구·저장을 대신하지 않고 실제 플레이 결과를 확인하며 진행 상태와 읽은 안내를 도시 저장에 보존합니다.
- 모든 플랫폼의 기본 UI 글꼴을 Galmuri11 도트 한글 폰트로 바꿨습니다. 번들 글꼴을 우선 로드하고 동적 아틀라스에 포인트 필터링을 적용합니다.
- 선택형 주민 AI의 Unity 클라이언트와 Node.js OpenRouter 게이트웨이를 구현했습니다. 모델이 제안한 주민 방문 계획은 허용된 목적지, 도시 세대와 실제 도로 경로를 다시 검사하며, 실패하거나 기능을 끄면 기존 규칙 기반 일과를 계속 사용합니다. 제공자 키는 게이트웨이에만 두고 주민 생각과 짧은 기억은 실행 세션에만 유지합니다.
- Windows 빌드에서 Feel, 시청 도착, 단우 튜토리얼·후속 안내, Galmuri11과 주민 AI `MOCK_CONTRACT` 흐름을 검사했습니다. OpenRouter API 키가 입력되지 않아 실제 모델 호출은 검증하지 않았습니다.
- 공개 GitHub 소스 저장소와 Windows Release 패키징 절차, 코어·게이트웨이 자동 검사를 추가했습니다. 이번 릴리스는 Windows용이며 v0.6 Android APK와 실제 기기는 미검증입니다.

- 상시 표시하던 큰 좌우 패널을 없애고, 상단 자원 바와 하단 도구 막대 중심으로 바꿨습니다.

- 같은 도시의 물류 규칙과 v4 저장 호환성은 유지합니다.

## v0.4 — 도시 안의 공장과 실제 물류

- 주택·도로·주민이 있는 같은 도시 땅에 공장 설비를 건설합니다. 도시 한 필지를 2×2 미세 칸으로 나누어 벨트·투입기·기계를 연결하며, 별도 공장 화면과 연습장 전환은 제거했습니다.
- 농장·벌목장 같은 도시 생산 건물에 투입기를 붙이면 생산물이 건물의 출고 버퍼에 쌓이고, 실제로 집어 벨트와 기계에 전달합니다. 완제품은 도로에 연결된 도시 창고·시장·시청에 도착할 때 도시 재고에 반영됩니다.
- 도시 가공 건물에도 투입기로 원료를 전달할 수 있습니다. 운송이 막히면 유한 버퍼가 차면서 생산이 멈추고, 도시 재고에 중복으로 더해지지 않습니다.
- 소유 영토·강·건물 점유를 함께 검사합니다. 채굴기는 자연 바위에 설치하며, 작은 운송 설비는 도로 위에 설치해 주민과 같은 공간을 사용합니다. 전력 인입기와 반출 부두에는 도시 도로 연결이 필요합니다.
- 도시 HUD에 설비·물류 탭, 방향·제조법·필터·재고 투입·검사기를 통합했습니다. Windows와 Android 모두 하나의 도시 카메라를 사용합니다.
- v4 저장은 도시와 이동 중 물류를 함께 보존합니다. 기존 v3의 분리된 공장은 원본을 보관하고 건설비 및 남은 물자를 한 번 전량 돌려준 뒤, 같은 도시에 재설계할 수 있도록 이전합니다. v1·v2 도시도 진행 상황을 유지하며 변환합니다.
- Windows x64와 Android ARM64 APK를 생성했습니다. PC 실행 검사와 APK 구성·서명 검사를 완료했으며 실제 Android 기기 동작은 아직 검사하지 않았습니다.

### 18개 기술과 모바일 지원

- 연구 기술을 9개에서 18개로 확장했습니다. 기존의 시대 진행 축은 유지되며 `길드`가 르네상스, `증기력`이 산업 시대를 열고 `도시 계획`이 3단계 증축과 최종 도시 목표를 해금합니다.
- 도시 생산 연구로 `산림 경영`(벌목장 +25%), `관개`(농장 +20%), `석공술`(채석장 +25%), `교육`(서재 레벨당 일일 연구 +1), `금속 공정 효율`(광산·제련소 +20%)을 추가했습니다.
- 공장 연구로 `물류`(벨트 속도 +50%), `전기화`(전력 수요 -15%), `대량 생산`(기계 제작 속도 +25%), `자동화`(투입기 속도 +50%)를 추가했습니다.
- 기존 v2·v3 도시는 완료한 연구와 현재 시대를 유지하며, 새 연구 가지를 이어서 진행할 수 있습니다.

## v0.3 — 물리 공장과 Android 빌드 준비

- 도시와 분리된 24×16 공장 부지를 추가했습니다. 벨트, 투입기, 채굴기, 용광로, 조립기, 저장고, 반입·반출 부두, 전력 인입기, 전신주와 분배기로 실제 물자를 운반하고 가공할 수 있습니다.
- 실제 공장은 빈 부지에서 시작하고 도시의 기술, 건설 자원과 남는 전력을 사용합니다. 반입한 도시 재고와 반출한 완제품, 철거 시 회수한 물자는 같은 도시 경제에 반영됩니다.
- 비용이나 기술 제한 없이 도구 생산선을 고칠 수 있는 연습 공장을 추가했습니다. 연습 공장의 배치와 물자는 도시 저장 및 생산 실적에 반영되지 않습니다.
- 도시와 공장을 하나의 v3 저장에 기록합니다. v2 저장은 기존 도시·연구·시대를 그대로 유지한 채 빈 실제 공장을 추가해 v3로 변환됩니다. v1 저장은 기존 도시 진행을 보존하기 위해 산업 시대와 현재 전체 기술 카탈로그를 승계한 뒤 빈 실제 공장을 추가합니다. 호환성을 위해 저장 파일명 `city-v1.json`은 유지합니다.
- Android 8.0(API 26) 이상, ARM64, IL2CPP, 가로 화면용 설정과 APK·Gradle 프로젝트 빌드 자동화를 추가했습니다. 도시와 공장에 한 손가락 탭·이동, 두 손가락 이동·핀치 확대와 시스템 뒤로 가기 동작을 연결했습니다.
- Windows x64 빌드와 실제 도시 자원을 사용하는 공장 런타임 흐름을 검증했습니다. Android ARM64 APK 생성, 서명과 패키지 구성 검사도 완료했습니다. 실제 Android 기기 동작은 검사하지 않았습니다.

## v0.2 — 시대 발전과 살아 있는 주민

- 새 도시가 중세에서 시작해 9개 핵심 기술을 연구하고 르네상스와 산업 시대로 발전하도록 만들었습니다. 연구에는 지식, 코인, 선행 기술과 시간이 필요하며 서재와 학술원이 연구 속도를 높입니다.
- 시대와 연구에 따라 건물, 2·3단계 증축과 증기 동력소를 해금하고, 건물과 도로의 외형 및 산업 시대 물류 차량이 함께 바뀌도록 했습니다.
- 주민마다 이름, 집, 일자리와 시장·공원 목적지를 부여했습니다. 주민은 실제로 연결된 도로와 다리를 따라 출근하고 장을 본 뒤 귀가하며, 선택하면 현재 목적지를 확인할 수 있습니다.
- 빵이 부족할 때 곡물로 식사를 대신하는 초기 생존 흐름과 연구·도시 진행을 저장하는 v2 형식을 추가했습니다.
