# v0.8~v0.9 복합 산업 가이드

RIVERWORKS의 산업망은 같은 42×42 미세 격자에서 고체 물류와 유체 배관을 함께 운용합니다. 카탈로그에는 코인 1종, 고체 30종, 유체 7종을 합친 38개 자원, 23개 설비, 37개 제조법이 있습니다. 생산의 큰 흐름은 `원료 추출 → 1차 가공 → 부품 → 고급 부품 → 제어 장치`입니다. 세 층 공장, 조건부 자동화와 도시 대형 프로젝트는 [v0.9 도시·공장 확장 가이드](EXPANSION_GUIDE.ko.md)를 참고하세요.

## 기본 운용 순서

1. 필요한 연구를 완료하고 원료 산지, 수원, 전력과 반출 경로를 확보합니다.
2. 생산 설비를 배치하고 `설비 구성`에서 호환 제조법을 선택합니다. 잠긴 제조법도 목록에 보이며 필요한 기술을 알려 줍니다.
3. 고체는 창고·반입 부두·벨트·분배기·투입기로, 유체는 펌프·파이프·분기점·탱크와 설비 유체 포트로 연결합니다.
4. 구성 화면의 배치당 투입·산출, 기본 시간과 분당 생산량을 확인합니다. 표의 수량은 고체는 `개`, 유체는 `L`, 시간은 기본 100% 클럭의 초 단위입니다.
5. 입력 버퍼, 출력 버퍼, 전력, 일시정지, 클럭과 막힘 상태를 확인한 뒤 완제품을 반출 부두로 보냅니다. 유체는 아이템 반출 부두로 보낼 수 없습니다.

제조법 변경은 호환 설비와 연구 조건을 먼저 검사합니다. 명시적 재구성을 사용하면 기존 입출력 물자를 도시 회수 재고로 돌려주고 진행도를 초기화합니다. 철거할 때도 설비 안의 고체와 유체는 회수 재고로 돌아갑니다.

## 원료 산지와 배치

철광석 채굴은 기존처럼 바위 지형을 사용합니다. 새 도시에는 구리 광석 `(16, 10)`, 석탄 `(10, 16)`, 보크사이트 `(16, 16)`, 원유 `(16, 4)` 도시 좌표에 조사된 산지가 마련됩니다. 채굴기는 선택한 채굴 제조법과 산지 자원이 맞아야 하며, 물 펌프는 물 지형, 원유 펌프는 조사된 유전 위에 배치해야 합니다. 산지가 이미 점유된 이전 도시에서는 구리 광석·석탄·보크사이트 교역을 원료 보완 수단으로 사용할 수 있습니다. 원유와 물은 교역할 수 없으므로 현장 배관이 필요합니다.

새 기계는 소유한 육지에 놓고, 파이프는 소유한 물 위도 지날 수 있습니다. 설비 방향은 고체 투입기와 유체 포트의 앞·뒤를 함께 결정하므로 배치 뒤 구성 화면의 포트와 화살표를 확인합니다.

## 고체와 유체의 경계

고체 30종만 아이템 화물이 될 수 있습니다. 벨트·분배기·투입기·창고·반입/반출 부두는 고체만 다루며 코인과 유체를 운반하지 않습니다. 유체 7종은 정수 리터 단위로 펌프, 파이프, 분기점, 탱크와 생산 설비의 지정 포트 사이에서만 이동합니다. 한 파이프나 탱크에는 한 종류의 유체만 들어가며 필터가 다르거나 다른 유체가 남아 있으면 혼합을 차단합니다.

파이프와 탱크는 뒤와 옆에서 유체를 받고 앞쪽으로 내보냅니다. 파이프 분기점은 앞과 왼쪽 두 방향으로 번갈아 분배합니다. 생산 설비의 유체 입력은 회전 기준 뒤쪽 두 포트, 유체 출력은 앞쪽 두 포트이며 제조법에 적힌 유체 순서대로 대응합니다. 설비를 회전하면 포트도 함께 회전하므로 연결 전에 입출력 표시를 확인해야 합니다.

파이프·분기점·생산 설비 출력의 기본 이송률은 8L/초, 유체 탱크는 12L/초입니다. 각 틱 시작 수량을 기준으로 옮겨 같은 틱에 여러 칸을 건너뛰지 않습니다. 이는 수량 기반의 방향성 배관 모델이며 압력, 중력, 양정은 계산하지 않습니다. 일시정지한 유체 설비는 밸브가 닫힌 것처럼 흐름을 막습니다.

## 생산, 부산물과 전력

한 배치는 필요한 모든 입력과 모든 출력 공간을 먼저 검사한 뒤 한 번에 처리합니다. 주산물 공간이 남아 있어도 부산물 공간이 가득 차면 입력을 소비하지 않고 `출력 또는 부산물 공간 부족` 상태로 멈춥니다. 원유 정제의 중유, 알루미나 정제의 실리카, 스크랩 정제와 배터리 조립의 재활용수까지 별도 출구와 저장 공간을 준비해야 합니다. 전력 부족, 일시정지, 원료 부족 또는 출력 막힘 동안 진행도는 보존됩니다.

생산 설비는 50%, 100%, 150%, 200% 클럭을 지원합니다. 150%와 200%는 `고급 제조` 연구가 필요합니다. 생산 속도는 클럭 비율에 비례하고 전력 수요는 비율의 제곱으로 늘어납니다. 예를 들어 기본 8 전력인 정유소는 50%에서 2, 150%에서 18, 200%에서 32 전력을 요구합니다. 파이프·탱크·벨트 같은 비생산 설비는 클럭을 조절할 수 없습니다.

## 설비 23종

버퍼는 입력/출력 총용량입니다. 파이프류는 단일 유체 저장 용량을 표시합니다.

|---|---:|---:|---:|---|---|

`필요 기술`은 제조법 자체의 조건입니다. 제조법에 별도 조건이 없어도 그 제조법을 실행할 설비의 해금 기술은 완료해야 합니다.

알루미늄 라인에서는 `알루미나 정제 → 스크랩 정제 → 알루미늄 제련 → 케이싱 성형`으로 이어집니다. 스크랩 정제와 배터리 조립에서 나온 물은 새 물과 합쳐 앞 공정으로 되돌릴 수 있습니다. 회수수가 막히면 해당 배치도 끝나지 않으므로 되돌림 배관과 여유 탱크를 함께 두는 편이 안전합니다.

## 산업 도감

`메뉴 → 산업 도감` 또는 설비 구성 창의 `산업 도감` 버튼으로 엽니다.

- `제조법 37`: 제조법명, 원료·산출 자원명과 영문 ID로 검색합니다. 카드를 펼치면 사용 가능 여부, 배치 비율, 기본 시간, 분당 산출량, 호환 설비, 공정 유형과 기본 전력을 확인할 수 있습니다.
- `자원 38`: 한글 자원명과 영문 ID로 검색하며 현재 도시 보유량, `개`/`L`/`G` 단위, 고체·유체·통화 구분과 교역 여부를 표시합니다.
- `생산 현황`: 배치된 설비와 가동 설비 수, 자원별 누적 생산·반출량을 표시합니다. `제어 장치 3개 반출`은 진행을 읽는 선택 목표이며 경제 값을 바꾸지 않습니다.

검색 입력 중에는 게임 단축키가 입력을 가로채지 않습니다. `Esc`로 도감을 닫을 수 있습니다.

상층 생산선을 만들 때도 이 문서의 37개 제조법과 고체·유체 규칙은 그대로 적용됩니다. 층간에는 화물 승강기 또는 유체 라이저만 사용할 수 있으며, 자동 조건 설정법과 대교·중앙 발전소·연구 단지의 재료표는 [v0.9 확장 가이드](EXPANSION_GUIDE.ko.md)를 참고하세요.

## 구현 시나리오의 검증 경계

코어의 원료부터 완제품까지 잇는 검사는 카탈로그 제조법을 원장 단계별로 넘겨 다음 공정에 투입하는 흐름입니다. 실제 벨트·투입기·파이프를 한 지도에서 끝까지 잇는 네이티브 실행 결과와 같은 뜻은 아닙니다.

네이티브 산업용으로 준비된 시나리오는 세 가지입니다. `석유 화학`은 원유·물의 배관, 원유 정제 부산물과 플라스틱 생산을, `알루미늄 재활용`은 알루미나·스크랩·실리카·재활용수 흐름을, `제어 장치 조립`은 준비된 컴퓨터·모터·배터리·모듈 프레임·알루미늄 케이싱을 벨트로 제조기에 공급하는 **최종 조립 단계**를 대상으로 합니다. 제어 장치 시나리오는 각 부품을 원료에서 생산하는 전체 체인을 검증하도록 구성된 시나리오가 아닙니다.

## 저장 호환성

현재 게임 저장 형식은 v6이고 공장 상태 형식은 v3입니다. v1~v4 도시 저장과 공장 v1의 기존 9칸 자원 배열은 먼저 기존 형식 그대로 검증해 v5/38칸으로 확장하고, 보존된 v5 상태를 다시 검증한 뒤 v6으로 확장합니다. 기존 도시 재고, 셀 물류 버퍼, 활성·보관 공장, 설비 입출력, 이동 화물, 생산·반출·회수 누계, 진행도, 유체, 클럭과 수동 일시정지를 보존합니다. 새 층·자동화·프로젝트 데이터는 빈 상태로 시작합니다. 자세한 변환 범위는 [확장 가이드의 저장 호환성](EXPANSION_GUIDE.ko.md#저장-호환성)을 참고하세요.

기존 18개 기술을 보유한 레거시 v1 저장이라도 새 산업 기술 8개를 자동 지급하지 않습니다. 새 기술은 [연구 트리 가이드](RESEARCH_TREE.ko.md)의 선행 조건에 따라 연구해야 합니다.
