# RIVERWORKS 산업 설비·물류 가이드

## 공장은 같은 도시입니다

공장 설비는 도시의 21×21 필지를 다시 42×42 미세 칸으로 나눠, 주택·농장·도로·주민과 같은 지도에 놓습니다. v0.5에서는 선택할 때만 건설 목록과 설비 정보가 열리는 작은 UI를 사용합니다. 별도 공장 바닥, 카메라, 연습 공장과 청사진 UI는 없습니다.

`설비 G` 버튼이나 `G` 키는 하단의 `설비`·`물류` 팔레트를 열고 닫습니다. 화면은 전환되지 않으며 데스크톱과 모바일 모두 같은 도시 카메라를 계속 사용합니다. 팔레트를 닫아도 이미 지은 설비와 실제 물자 이동은 도시 시간에 맞춰 계속 작동합니다.

## 격자와 필지

- 도시 좌표 `(x, z)` 하나는 설비 미세 좌표의 2×2 영역입니다.
- 2×2 설비는 도시 필지 하나와 같은 크기이며 짝수 미세 좌표의 필지 경계에 맞춰 배치됩니다.
- 1×1 설비는 도시 필지의 1/4을 차지합니다.
- 방향은 `동쪽(+X) → 북쪽(+Z) → 서쪽(-X) → 남쪽(-Z)` 순으로 회전합니다.
- 설비의 좌표는 오른쪽 검사기에 `미세 좌표`로 표시됩니다.

```text
도시 필지 1칸                 설비 미세 칸 2×2

┌─────────────┐              ┌──────┬──────┐
│             │              │ x,z+1│x+1,z+1│
│   2×2 기계  │      =       ├──────┼──────┤
│             │              │ x,z  │x+1,z │
└─────────────┘              └──────┴──────┘
```

## 배치 조건

도시가 지형과 점유의 기준입니다.

- 모든 설비는 구매한 지역 안에 놓아야 합니다.
- 채굴기는 점유한 2×2 미세 칸 중 하나 이상이 도시의 실제 `바위` 필지와 겹쳐야 합니다. 예전 공장 전용 고정 광맥은 사용하지 않습니다.
- 2×2 기계, 설비 창고, 부두와 전력 인입구는 물 위에 놓을 수 없습니다.
- 벨트·투입기·전신주·분배기는 도시 도로와 같은 필지에 놓을 수 있습니다.
- 물 위에 경량 물류 설비를 놓으려면 그 필지에 도시 도로 교량이 먼저 있어야 합니다. 그 설비를 철거하기 전에는 아래 교량도 철거할 수 없습니다.
- 도시 건물이 있는 필지는 설비 배치를 막습니다. 설비가 차지한 필지에도 도시 건물을 지을 수 없습니다.
- 기계가 있는 필지에는 도로를 겹쳐 지을 수 없습니다. 도로와 경량 물류 설비만 예외적으로 공존합니다.
- 설비끼리는 미세 칸 하나라도 겹칠 수 없습니다.

배치 미리보기의 윤곽과 방향 화살표로 점유 범위를 확인하세요. 배치가 거부되면 코인·목재·석재가 차감되지 않습니다.

## 물자가 이동하는 규칙

```text
집는 쪽                   놓는 쪽
도시 생산지/설비 ──▶ [투입기 ▶] ──▶ 벨트/기계/도시 접점
```

- 벨트는 한 번에 물자 하나를 싣습니다. 출구가 열릴 때만 다음 미세 칸으로 넘기고, 막히면 물자를 보존한 채 기다립니다.
- 투입기는 방향의 바로 뒤에서 한 개를 집어 바로 앞에 놓습니다. `모든 물자` 필터는 아무 자원이나, 특정 필터는 그 자원만 집습니다.
- 분배기는 앞과 왼쪽을 번갈아 시도합니다. 한쪽이 막히면 다른 쪽으로 보냅니다.
- 채굴기는 2초마다 광석을 만들며 앞쪽으로 내보냅니다.
- 용광로와 조립기는 벨트에서 직접 원료를 받지 않습니다. 투입기가 원료를 넣고, 완제품도 투입기가 꺼냅니다.
- 설비 창고·반입 부두·반출 부두는 80개를 보관합니다. 생산 설비의 입력 합계와 출력 합계는 각각 24개입니다.
- 원료가 둘인 도구 제조법은 한 종류가 입력을 독점하지 않도록 종류별 12개까지만 받습니다.
- 이동 중이거나 버퍼에 있는 물자는 성공한 제조 변환, 도시 인계 또는 철거 회수 전까지 사라지지 않습니다.

## 도시 생산 시설과 직접 연결

도시 시설도 실제 물류의 입출력 지점입니다. 투입기의 뒤와 앞 미세 칸이 어느 도시 필지에 속하는지로 연결을 판정합니다.

### 생산물을 꺼낼 때

농장, 벌목장, 채석장, 광산과 모든 가공 시설을 투입기의 집는 쪽에 맞추면 그 시설의 이후 생산물은 도시 공유 재고로 바로 가지 않고 `LogisticsOutput`에 쌓입니다. 투입기는 정수 1개가 준비될 때마다 실제 물자로 꺼냅니다. 생산량의 소수 부분도 버퍼에 보존됩니다.

출력 버퍼 전체 용량은 80개입니다. 벨트가 막혀 버퍼가 가득 차면 도시 시설은 해당 날짜에 원료를 소비하지 않고 생산을 기다립니다.

### 가공 시설에 넣을 때

제분소·제과점·제련소·공방을 투입기의 놓는 쪽에 맞추면 물자가 `LogisticsInput`에 들어갑니다. 이 시설은 자동화된 동안 도시 공유 재고 대신 물리 입력 버퍼에서 제조법 원료를 소비합니다.

입력 자동화와 출력 자동화는 독립적입니다. 예를 들어 제분소 입력만 자동화하고 밀가루는 당분간 공유 재고로 보낼 수 있습니다. 투입기를 붙이지 않은 다른 시설은 기존 도시 경제 방식으로 계속 가동하므로 오래된 도시를 한 번에 다시 설계할 필요가 없습니다.

### 공유 재고로 보내고 꺼낼 때

| 도시 접점 | 받기 | 내보내기 |
|---|---|---|
| 연결된 시청 | 코인을 제외한 모든 물자 | 공유 재고의 모든 물자 |
| 연결된 도시 창고 | 코인을 제외한 모든 물자 | 공유 재고의 모든 물자 |
| 연결된 시장 | 빵·도구 | 지원하지 않음 |
| 도로에 닿은 반출 부두 | 보관 중인 모든 물자를 자동 반출 | 지원하지 않음 |
| 설비 창고·반입 부두 | 벨트·투입기 또는 구성 창의 수동 투입 | 보관 물자를 투입기가 꺼냄 |

시청, 도시 창고와 시장은 시청 도로망에 연결되어 있어야 합니다. 반출 부두와 전력 인입구도 인접한 도시 도로 또는 시청이 연결 상태여야 작동합니다. 연결이 끊기면 물자는 사라지지 않고 현재 위치에서 기다립니다.

## 제조법

| 설비 | 제조법 | 입력 | 출력 | 시간 |
|---|---|---|---|---:|
| 용광로 | 강철 제련 | 광석 2 | 강철 1 | 4초 |
| 조립기 | 도구 | 강철 1 + 목재 1 | 도구 1 | 6초 |
| 조립기 | 밀가루 | 곡물 2 | 밀가루 2 | 4초 |
| 조립기 | 빵 | 밀가루 2 | 빵 3 | 5초 |

설비를 선택하고 오른쪽 검사기의 `설비 구성`을 열어 제조법을 정합니다. 제조법을 바꾸면 기존 입력·출력 버퍼는 도시 재고로 회수되고 진행률은 0으로 초기화된 뒤 새 제조법이 적용됩니다.

## 전력

전력 인입구는 인접한 연결 도로나 시청을 통해서만 전력망의 시작점이 됩니다. 도시 생산 시설이 먼저 쓰고 남은 풍차·증기 동력을 설비가 공유합니다.

- 전력 인입구와 전신주는 점유 영역의 가장 가까운 가장자리 사이 거리가 6칸 이내면 같은 망으로 이어집니다.
- 채굴기·용광로·조립기·투입기는 활성 인입구나 전신주에서 같은 기준 4칸 이내일 때 전력을 받습니다.
- X와 Z 간격 중 큰 값을 쓰므로 대각선 한 칸도 거리 1입니다.
- 2×2 설비는 좌표 기준점이 아니라 점유한 직사각형의 가장 가까운 가장자리부터 거리를 잽니다.
- 도시의 남는 전력보다 설비 수요가 많으면 일부 설비가 멈춥니다.

오른쪽 검사기에서 선택 설비의 `공급됨` 또는 `공급 필요`, 수요와 상태를 확인할 수 있습니다.

선택 연구의 설비 효과는 다음과 같습니다.

| 기술 | 효과 |
|---|---|
| 물류 | 벨트 속도 ×1.5 |
| 전기화 | 투입기·채굴기·용광로·조립기 전력 수요 ×0.85 |
| 대량 생산 | 채굴기·용광로·조립기 작업 속도 ×1.25 |
| 자동화 | 투입기 속도 ×1.5 |

## 처음 만드는 두 생산선

### 농장 곡물을 제분소로 보내기

1. 농장과 제분소가 시청 도로망에 연결되어 있는지 확인합니다.
2. 농장 필지의 가장자리를 집는 쪽으로 보는 투입기를 놓습니다.
3. 투입기 앞에서 제분소 방향으로 벨트를 잇습니다.
4. 마지막 벨트 뒤에 투입기를 놓고 그 앞쪽 미세 칸이 제분소 필지 안에 닿게 합니다.
5. 전력 인입구를 연결 도로 옆에 놓고, 전신주로 두 투입기에 전력을 공급합니다.
6. 농장의 `LogisticsOutput`에서 곡물 물체가 나오고 제분소의 `LogisticsInput`으로 들어가는지 검사기에서 확인합니다.

제분소 출력에도 같은 방식으로 투입기를 붙이면 밀가루를 제과점이나 연결된 도시 창고로 실제 운송할 수 있습니다.

### 실제 바위에서 강철·도구 만들기

1. `금속학`을 연구하고 구매한 지역의 바위 필지를 찾습니다.
2. 바위와 겹치도록 2×2 채굴기를 놓고 앞쪽에 벨트 또는 투입기를 연결합니다.
3. 용광로를 놓고 `설비 구성`에서 `강철 제련`을 확인합니다. 투입기로 광석을 넣고 다른 투입기로 강철을 꺼냅니다.
4. `도구 제작` 뒤 조립기에 `도구` 제조법을 선택합니다.
5. 강철 선과 목재 선을 조립기에 연결하고 각 투입기에 `강철`, `목재` 필터를 지정합니다.
6. 완성된 도구를 연결된 시청·도시 창고·시장에 직접 넣거나, 도로에 닿은 반출 부두로 보냅니다.

목재는 벌목장에서 직접 꺼내거나 연결된 시청·도시 창고의 공유 재고에서 꺼낼 수 있습니다. 설비 창고 또는 반입 부두를 선택해 `설비 구성`에서 10개씩 수동 투입하는 방법도 있습니다.

## 검사기와 조작

설비를 선택하면 오른쪽 검사기에 다음 정보가 표시됩니다.

- 설비 ID와 미세 좌표
- 방향과 점유 크기
- 전력 공급 여부와 수요
- 제조법 또는 투입기 필터
- 입력·출력 재고, 운반 물자, 공정 진행률과 상태

`설비 구성` 모달은 용광로·조립기의 제조법, 투입기 필터, 설비 창고·반입 부두의 수동 투입만 표시합니다. `닫기`를 누르면 같은 도시 화면으로 돌아옵니다.

| 동작 | 데스크톱 | Android |
|---|---|---|
| 설비 팔레트 | `G` 또는 `설비 G` | `산업 설비`와 `설비`·`물류` 탭 |
| 배치·선택 | 좌클릭, 벨트는 드래그 | 짧게 탭 |
| 방향 회전 | `R` | `회전` 버튼 |
| 철거 | `Delete` 또는 `철거` | `철거` 버튼 |
| 도구 취소 | `Esc` 또는 짧은 우클릭 | `취소` 또는 시스템 뒤로 |
| 카메라 이동 | 우클릭/가운데 버튼 드래그, `WASD` | 도구가 없을 때 한 손가락, 언제나 두 손가락 드래그 |
| 확대·축소 | 마우스 휠 | 두 손가락 핀치 |
| 구성 | 선택 후 `설비 구성` | 선택 후 `설비 구성` |

선택한 설비에는 도시 위에 점유 윤곽이 남습니다. 운반 중인 물자가 있는 벨트·분배기·투입기는 물자를 넘길 때까지 회전할 수 없습니다.

## 철거와 저장

설비 철거 시 입력·출력과 운반 중 물자는 모두 도시 공유 재고로 회수됩니다. 건설비는 코인·목재·석재 각각 35%를 돌려받습니다. 가공 진행률 자체는 물자가 아니므로 사라집니다.

현재 저장 형식은 v4입니다. 활성 설비는 `Factory`의 42×42 공유 도시 격자에 저장됩니다. v3의 별도 24×16 공장은 처음 불러올 때 `ArchivedFactory`에 원본 그대로 보관되지만 실행·표시되지 않습니다. 그 안의 물자와 전체 건설비는 도시로 한 번 반환되고, 활성 격자는 빈 상태에서 시작합니다. 보관본을 다시 생산에 투입하거나 자동으로 재배치하는 기능은 없습니다.

현재 물류는 물자 하나씩 이동하는 단일 차선 벨트와 투입기 중심입니다. 유체, 지하 벨트, 기차와 전투는 포함하지 않습니다.
