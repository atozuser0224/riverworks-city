# 마을 서기 단우의 안내

새 도시는 시청 도착 연출로 시작합니다. 카메라가 시청을 가까이 보여준 뒤 마을로 돌아옵니다. 시청이 자리를 잡으면 실제 주민인 친절한 마을 서기 단우가 한 글자씩 말하며 안내합니다. 인트로는 건너뛰기 버튼, PC의 Esc 또는 Android 뒤로 가기로 넘길 수 있습니다.

단우는 다른 주민과 같은 3D 모델과 도로 경로를 사용하며 청록색 옷으로 구분됩니다. 안내 중에는 설명하는 곳 옆의 도로로 걷고 카메라가 따라갑니다. 휠·드래그·핀치로 직접 카메라를 움직이면 추적을 멈춥니다. `단우 보기`를 누르면 다시 따라갑니다. 대화창에는 초상 그림을 표시하지 않고 갈무리 도트풍 한글 폰트를 사용합니다.

## 대화 읽기

- 대화가 나오는 중에 본문이나 진행 버튼을 누르면 현재 페이지를 즉시 표시합니다.
- 다시 누르면 다음 페이지를 읽습니다. 마지막 페이지를 확인해야 안내 단계가 진행됩니다.
- 실제 행동이 필요한 단계는 설명을 확인하면 작은 안내 표시로 접힙니다.
- 작은 안내 표시를 누르면 설명을 다시 볼 수 있습니다.
- 메뉴의 `단우에게 조언 듣기`에서 안내를 다시 열 수 있습니다.
- 도시에서 단우를 직접 눌러도 안내 대화를 열 수 있습니다.
- 효과 줄이기와 전체 음소거 설정을 따릅니다. 대화 도중 Space/Enter는 대화를 진행합니다.

## 첫 마을의 11단계

환영 → 시청 선택 → 연결된 도로 확장 → 주택 → 벌목장 → 서재 → 윤작 연구 시작 → 1× 시간으로 연구 완료 → 기계 동력과 생산망 설명 → 수동 저장 → 첫 마을 안내 완료.

단우는 플레이어 대신 건물을 짓거나 자원을 주지 않습니다. 실제 연결된 시설, 선택, 연구 완료와 저장 성공을 확인합니다. 이미 시작부터 있던 도로·주택을 새로 만든 것으로 세지 않습니다.

## 성장하면서 배우기

기초 안내 뒤에는 현재 기술과 인구에 맞는 기능을 한 번에 하나씩 소개합니다. 증축, 식량 사슬, 전력, 행복·주택, 영토, 시장·교역, 창고, 금속·도구, 증기 동력, 미세 격자, 벨트·투입기, 제조법·버퍼, 분배·필터·적체, 물자 인계, 선택 연구, 주민 AI, 저장·화면 효과를 포함한 19개 기능 안내가 있습니다.

자동 안내 사이에는 간격을 두며 건설 도구나 다른 창을 사용하는 동안에는 끼어들지 않습니다. 마지막 페이지까지 읽고 확인한 안내만 읽음으로 기록합니다. 자동 기능 팁은 끌 수 있습니다.

조언 모드에서 `... → 기능 목록`을 누르면 19개 설명을 모두 골라 읽을 수 있습니다. 목록 오른쪽 위의 X로 닫습니다. `처음부터`, `건너뛰기`, `다음 기능`, `기능 팁`도 `...`에서 찾을 수 있습니다. 잠긴 기술도 설명을 미리 읽을 수 있으며, 기술이나 시설이 해금되는 것은 아닙니다. 도시·생산·연구·공장·영토의 다섯 주제로도 질문할 수 있습니다.

## 저장과 다시 시작

단계, 건너뛰기 상태, 읽은 기능과 시청 인트로 재생 여부를 도시 저장에 기록합니다. 대화의 글자 위치는 저장하지 않으므로 현재 설명을 다시 읽을 수 있습니다. 저장을 불러올 때 시청 도착 연출을 반복하지 않습니다.

이전 버전 도시는 자동으로 안내를 시작하지 않습니다. 메뉴에서 직접 열면 시작할 수 있습니다. 건너뛰었던 안내는 같은 단계에서 이어갈 수 있고, 다시 시작은 현재 도시를 그대로 둔 채 새 기준으로 안내합니다.
