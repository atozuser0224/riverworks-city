# 주민 AI 연결

주민 AI는 OpenRouter의 언어 모델이 여러 주민의 다음 행동을 결정하고, 게임이 허용된 목적지와 실제 도로 경로를 확인해 적용하는 기능입니다. 집·직장·시장·공원·시청 방문 중에서 선택하며, 건설·재고·세금·생산 규칙을 모델이 변경하지는 않습니다.

실제 모델 응답이 없으면 기존 일과로 움직이며 화면에도 기본 일과로 표시합니다. 주민의 최근 생각·기분·짧은 기억은 현재 실행 세션에만 유지합니다. 도시 저장에 장기 기억을 보관하는 기능은 아직 없습니다.

## 서버 시작

Node.js 22 이상이 필요합니다. 프로젝트의 `Server/.env`에 `OPENROUTER_API_KEY`를 설정한 뒤 PowerShell에서 실행합니다.

```powershell
.\Server\start.ps1
```

서버는 기본적으로 `http://127.0.0.1:47841`에서 동작합니다. 게임의 `메뉴 → 주민 AI`에서 연결 상태를 확인합니다. 키를 변경했다면 서버를 다시 시작합니다.

OpenRouter API 키는 서버에서만 사용하며 게임·APK·Drive 배포 파일·로그에 넣지 않습니다. `.env.example`만 배포 대상입니다. 게임의 연결 키 입력란은 별도 게이트웨이 접근 토큰용이며 OpenRouter API 키 입력란이 아닙니다.

## 호출과 비용

기본 모델은 `google/gemini-2.5-flash-lite`입니다. 2026-09-14 조회한 OpenRouter 카탈로그 가격은 입력 100만 토큰당 $0.10, 출력 100만 토큰당 $0.40입니다. 가격과 제공 여부는 [공식 모델 카탈로그](https://openrouter.ai/api/v1/models)에서 확인할 수 있습니다.

- 한 번에 최대 16명의 계획을 요청하고 주민들을 순서대로 순환합니다.
- 기본 요청 간격은 30초 이상이며 서버는 분당 최대 2회로 제한합니다.
- 서버는 동시에 하나의 모델 요청만 실행합니다.
- 시간당 $0.50, 하루 $2의 보수적인 비용 한도를 적용합니다. 실제 결제 상한은 OpenRouter 키 설정에서도 관리할 수 있습니다.
- 실패·시간 초과·잘린 JSON·허용되지 않은 목적지는 적용하지 않습니다.
- 도시를 바꾸거나 연결을 끄면 이전 요청과 주민 계획을 무효화합니다.

## Android와 다른 PC

기본 localhost 주소는 해당 기기 자신을 의미합니다. 다른 기기에서 사용하려면 접근 가능한 게이트웨이 주소를 설정해야 합니다. 외부 주소는 HTTPS, 로컬 테스트 주소는 루프백 또는 사설 LAN만 허용합니다. 서버를 루프백 밖에 바인딩할 때는 별도 접근 토큰이 필요합니다. 게이트웨이 토큰은 게임 실행 중 메모리에만 보관합니다.

현재 실제 Android 기기의 네트워크·화면·조작 검증은 별도이며, APK 생성 성공을 기기 검증으로 간주하지 않습니다.

## 검증 구분

Node 모의 테스트, Unity의 `MOCK_CONTRACT` HTTP 검사, 실제 OpenRouter를 사용하는 `LIVE_OPENROUTER` 검사는 별개입니다. 모의 응답으로 실제 모델 호출 성공을 주장하지 않습니다. 현재 실호출 가능 여부와 최신 결과는 [검증 기록](VERIFICATION.md)을 확인합니다.
