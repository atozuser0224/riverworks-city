# 연구 트리 가이드

연구 창은 26개 기술과 35개 선행 관계를 12단계 깊이, 중세·르네상스·산업 시대의 세 구역으로 펼쳐 보여 줍니다. 기술 카드를 선택하면 그 기술과 모든 선행 기술이 강조되고, 둘 이상의 선행 기술이 있는 곳은 연결된 기술을 **모두** 완료해야 합니다. 예를 들어 길드는 `석조술`과 `기계 동력`을, 산업 제어는 `고급 제조`, `에너지 저장`, `자동화`를 모두 요구합니다.

![연구 트리 화면](Images/research-tree-v0.7.png)

시대 구역은 기술 분류이며 연구 가능 여부는 실제 선행 조건과 자원으로 판단합니다. 기존 18개 연구의 비용, 선행 조건과 효과는 그대로 유지되고 산업 기술 8개가 뒤에 연결됩니다. 현재 저장 형식은 v5이며 이전 v1~v4 저장을 불러올 수 있습니다. 연구를 시작하면 지식과 코인을 한 번 지불하고 정해진 날짜가 지나야 완료됩니다. 일일 지식 생산량은 다음 연구를 위한 지식을 모으지만, 이미 시작한 연구의 남은 기간을 줄이지 않습니다.

## 열기와 이동

- 상단 오른쪽의 연구 버튼 또는 `T` 키로 연구 창을 열고 닫습니다. 검색 입력란에 글자를 쓰는 동안에는 `T`와 `G` 단축키가 작동하지 않아 입력이 끊기지 않습니다.
- 빈 지도 영역을 마우스 왼쪽 버튼으로 끌거나 터치로 드래그해 이동합니다. 휠은 좌우, `Shift+휠`은 상하로 이동합니다.
- `−`와 `+` 또는 `Ctrl+휠`로 100%와 200% 사이를 정수 단계로 확대합니다. 화면 안에 선택한 기술이 보일 때 확대하면 그 기술이 계속 보이도록 중심을 잡습니다.
- 하단의 `중세`, `르네상스`, `산업 시대`를 누르면 해당 시대의 연구 가능한 첫 기술로 이동합니다. `현재 연구`는 진행 중인 기술로, 진행 중인 기술이 없으면 연구 가능한 기술로 이동합니다.
- `처음으로`는 검색과 필터를 지우고 100% 배율과 트리 시작 위치로 돌아갑니다. 오른쪽 아래 작은 지도에서 원하는 위치를 클릭해 곧바로 이동할 수도 있습니다.

## 카드 상태와 연결선

각 카드는 `완료`, `진행 중`, `가능`, `대기`, `잠김` 상태와 지식·코인·기간을 함께 표시합니다. 완료한 기술에서 나가는 선은 완료 색으로, 선택한 기술까지 이어지는 모든 조상 기술과 선은 경로 색으로 강조됩니다. AND 합류도 각 선을 따로 그리므로 필요한 분기를 눈으로 확인할 수 있습니다.

검색은 한글 기술명, 영문 기술 ID, 설명, 효과, 해금 건물과 공장 설비 이름을 함께 찾습니다. `전체`, `연구 가능`, `미완료` 필터와 검색어를 같이 사용할 수 있으며, 조건에 맞지 않는 카드는 사라지지 않고 흐려져 트리의 맥락을 유지합니다. `다음`을 누르면 일치하는 기술을 차례로 선택하고 중앙에 표시합니다.

## 오른쪽 상세 정보와 연구 경로

기술을 선택하면 오른쪽에 설명, 현재 상태, 비용, 실제 적용 수치, 해금되는 도시 시설과 공장 설비, 직접 선행 기술, 다음 기술이 표시됩니다. 진행 중인 기술은 진행률, 남은 일수와 예상 완료일도 보여 줍니다.

`연구 경로`는 선택한 기술까지 아직 필요한 모든 기술을 위상 순서로 미리 보여 주고, 지식·코인·기초 연구 일수의 합계를 계산합니다. 이미 완료한 기술은 합계에서 빠지며, 경로 안에서 진행 중인 연구는 이미 낸 비용을 다시 더하지 않고 남은 일수만 계산합니다. 표시된 합계는 **자원 대기 제외** 값이며, 자원을 모으느라 기다리는 시간과 경로 밖에서 진행 중인 다른 연구의 대기 시간은 포함되지 않습니다.

경로는 계획을 읽기 위한 미리보기입니다. `첫 단계로 이동`을 누른 뒤 해당 카드의 `연구 시작`을 직접 눌러 진행합니다. 이후 단계도 완료 조건과 자원을 확인해 같은 방식으로 시작합니다.

자동화 경로는 합류 구조를 가장 잘 보여 주는 예입니다. `윤작 → 기계 동력` 분기와 `석조술`이 길드에서 합쳐지고, 이후 `학문 → 증기력 → 전기화`와 `금속학 → 도구 제작 → 대량 생산`을 모두 마쳐야 자동화를 시작할 수 있습니다. 증기력 자체도 학문과 도구 제작을 함께 요구합니다. 공통 조상은 경로와 비용 합계에 한 번만 포함됩니다.

새 산업의 최종 목표인 산업 제어는 세 갈래를 다시 합칩니다. `전자공학 → 고급 제조`, `알루미늄 가공 + 석유화학 → 에너지 저장`, 기존 `자동화`를 모두 완료해야 제어 장치 조립을 연구할 수 있습니다. 설비와 37개 제조법의 자세한 연결은 [복합 산업 가이드](INDUSTRY_GUIDE.ko.md)를 참고하세요.
