# RIVERWORKS 플레이어 가이드

## 목표

중세 정착지에서 도로와 생산 시설을 연결하고 지식을 모아 기술을 연구하세요. 기존 발전·생산 기술 18종과 복합 산업 기술 8종, 모두 26종이 있습니다. 르네상스와 산업 시대로 발전해 광산·제련소·공방과 실제 물류망을 완성하고, 인구 45명·지역 4곳·`도시 계획` 연구를 달성하면 대도시가 됩니다. 그 뒤에는 석유화학·알루미늄·전자·배터리와 제어 장치 생산망을 선택적으로 확장할 수 있습니다.

RIVERWORKS v0.9에서는 도시 건물, 대형 프로젝트와 지상·2층·3층 산업 설비를 같은 지도에 놓습니다. 주민, 고체 물자, 파이프의 유체 흐름과 층간 운송도 한 카메라에서 함께 보입니다.

## 작은 UI 사용하기

- 하단의 건설 분류를 누르면 목록이 펼쳐집니다. 같은 분류를 다시 누르거나 `도구` 버튼을 누르면 접습니다.
- 건설 도구를 고르면 목록이 접히고 현재 도구·취소·회전만 작은 막대에 표시됩니다.
- 건물·설비·주민을 선택했을 때만 오른쪽 정보가 열립니다. `닫기`는 선택도 해제합니다.
- 왼쪽의 목표 요약을 누르면 상세 목표를 펼칩니다.
- 하단 `현황`, `영토`, `교역`으로 도시 통계·지역 구매·10개 단위 구매 및 판매 창을 엽니다.
- `메뉴`에서 저장·불러오기·새 도시·도움말을 사용할 수 있습니다. 기존 단축키도 그대로 동작합니다.

## 단우의 기존 안내

새 도시의 첫 마을 안내는 기존 **11단계**, 기본 안내 뒤 기능 설명은 **19개 레슨**을 그대로 유지합니다. 단우는 도시의 실제 주민으로 목표 옆 도로를 걸으며 카메라 추적과 `단우 보기`, More 메뉴, 저장된 안내 진행 상태도 이전과 같습니다. v0.8·v0.9 확장은 기존 튜토리얼 단계나 읽음 비트를 다시 번호 매기지 않습니다. 복합 산업은 `산업 도감`, 층별 공장과 프로젝트는 [도시 확장 가이드](EXPANSION_GUIDE.ko.md)에서 이어서 배울 수 있습니다.

## 처음 시작하기

새 도시는 중앙 5번 지역의 중세 마을입니다. 시청은 `(10, 10)`, 주택은 `(9, 9)`와 `(11, 9)`, 농장은 `(9, 8)`에 있습니다. 짧은 십자형 도로는 시청에서 `(10, 8)`, `(8, 10)`, `(12, 10)`까지 이어집니다.

1. `(7, 10)`의 숲에 `벌목장`을 지으세요. 시작 도로 끝에 바로 연결됩니다.
2. `석조술`을 연구한 뒤 `(13, 10)`의 바위 근처에 `채석장`을 지으세요.
3. `(11, 8)` 같은 도로 옆 빈 평지에 `서재`를 지어 연구 속도를 높이세요. 이미 사용 중이면 같은 도로에 인접한 조건 맞는 빈 필지를 사용합니다.
4. `T`로 연구 창을 열어 `윤작`을 시작하세요. 연구 창이 열린 동안 도시는 멈추고, 연구 시작 버튼을 누르면 창이 닫혀 날짜가 다시 흐릅니다.
5. 초반에는 농장의 곡물로 주민을 먹일 수 있습니다. 곡물 식사는 빵보다 행복과 성장 효과가 낮으므로 `윤작 → 기계 동력` 뒤 풍차·제분소·제과점을 연결하세요.
6. 자동화는 나중에 조금씩 추가해도 됩니다. 투입기가 없는 생산 시설은 기존 도시 공유 재고를 계속 사용합니다.

좌표와 지형은 필지를 선택한 뒤 오른쪽 검사기에서 확인합니다.

## v0.8 자원과 복합 산업

공유 재고는 **38개 자원 슬롯**을 가집니다. 코인 1종, 벨트·투입기로 옮기는 고체 30종, 파이프로 옮기는 유체 7종입니다.

- 기존 경제: 목재, 석재, 곡물, 밀가루, 빵, 철광석, 강철, 도구
- 광물·기초 부품: 구리 광석, 구리, 석탄, 기어, 전선, 강철 보, 강철 파이프, 보크사이트, 실리카
- 석유·화학·전자: 플라스틱, 고무, 황, 회로 기판, 모터, 고급 회로, 컴퓨터
- 알루미늄·제어: 알루미늄 스크랩, 알루미늄, 알루미늄 케이싱, 배터리, 모듈 프레임, 제어 장치
- 유체: 물, 원유, 중유, 석유 가스, 황산, 알루미나 용액, 연료

교역은 모든 자원을 자유롭게 만들 수 있는 경로가 아닙니다. 기존 교역품 8종에 구리 광석·석탄·보크사이트를 더한 11종만 사고팔 수 있고, 나머지 중간재·완제품과 모든 유체는 산업 설비로 생산해야 합니다. 새 도시의 특수 자원지는 구리 `(16,10)`, 석탄 `(10,16)`, 보크사이트 `(16,16)`, 원유 `(16,4)` 도시 필지에 표시됩니다. 철광석은 기존처럼 바위 지형에서, 물은 수면에서 얻습니다. 이전 도시의 지형과 건물은 새 자원지를 위해 강제로 바꾸지 않으므로 원료 교역을 대체 출발점으로 사용할 수 있습니다.

37개 제조법은 `메뉴 → 산업 도감` 또는 생산 설비의 `설비 구성 → 산업 도감`에서 검색할 수 있습니다. 도감은 자원 단위, 필요한 설비·기술, 입력·출력과 기본 분당 생산량을 보여 줍니다. 전체 공정표와 추천 생산선은 [복합 산업 가이드](INDUSTRY_GUIDE.ko.md)를 참고하세요.

## v0.9 도시 프로젝트

`메뉴 → 도시 프로젝트`에서 세 프로젝트의 부지, 현재 단계, 남은 자재와 보상을 확인합니다. 같은 종류는 도시에 하나만 둘 수 있고, 프로젝트 전체 부지가 소유 지역 안에 있어야 합니다. 다른 도시 건물·공장 설비·플랫폼·프로젝트와 겹칠 수 없습니다.

| 프로젝트 | 크기·기술·시작 비용 | 3단계 | 완공 효과 |
|---|---|---|---|
| 대교 | 4×1, 도시 계획, 400G | 석재 20+강철 보 12, 2일 → 강철 파이프 16+모듈 프레임 8, 2일 → 모터 4+제어 장치 2, 2일 | 네 필지가 실제 레벨 1 도로가 됨 |
| 중앙 발전소 | 2×2, 고급 제조, 600G | 석재 30+강철 보 10, 2일 → 모터 8+강철 파이프 20+모듈 프레임 10, 3일 → 컴퓨터 4+배터리 8+제어 장치 4, 2일 | 도로 연결과 석탄 2개/일로 전력 +80 |
| 연구 단지 | 2×2, 고급 제조, 500G | 석재 20+강철 보 8, 2일 → 회로 기판 12+모듈 프레임 8, 2일 → 컴퓨터 8+제어 장치 3, 3일 | 도로 연결 시 연구 +10/일 |

1. `부지 선택`을 누른 뒤 도시의 실제 필지를 선택합니다. 대교는 양 끝이 육지이고 내부에 수면이 하나 이상 있어야 하며, 한쪽 끝에 시청과 연결된 도로가 닿아야 합니다.
2. 현재 단계의 고체 자재를 도시 재고에 준비하고 `현재 단계 재료 지급`을 누릅니다. 가능한 수량만 요구량까지 이동하며 자동 납품이나 유체 납품은 없습니다.
3. 단계 자재가 모두 지급되면 공사일이 시작됩니다. 도로 연결이 끊기면 남은 일수가 줄지 않습니다.
4. 진행 중 취소하면 현재 단계에 지급한 자재 전부와 시작 비용의 35%를 돌려받습니다. 이미 완료한 단계의 자재는 소비된 상태이고 완공 프로젝트는 취소할 수 없습니다.

대교 완공 도로는 실제 주민·건물 연결 경로에 쓰이며 개별 도로 철거 대신 프로젝트 상태로 보호됩니다. 중앙 발전소의 전력 미리보기는 석탄을 쓰지 않고, 실제 하루 틱에서 석탄 2개를 한 번만 소비한 날에 전력 80을 냅니다. 연구 단지는 연결된 날마다 고정 연구 10을 더합니다.

## v0.9 지상·2층·3층 공장

코드의 층 `0/1/2`는 화면에서 `지상/2층/3층`으로 표시됩니다. 기존 여섯 건설 분류는 유지되며, `PageUp`·`PageDown` 또는 `설비`·`물류` 팔레트의 접을 수 있는 층 선택 띠로 현재 층을 바꿉니다. 선택한 층과 그 아래층은 보이고 위층은 숨겨져 배치 위치를 읽을 수 있습니다.

- 상층 설비는 2×2 미세 칸 플랫폼 전체의 지지를 받아야 합니다. 2층 플랫폼은 `대량 생산`, 3층 플랫폼은 `고급 제조` 연구가 필요합니다.
- 플랫폼 한 장은 30G·강철 보 2·모듈 프레임 1입니다. 3층 플랫폼은 같은 위치의 2층 플랫폼이 먼저 있어야 합니다.
- 플랫폼 위 설비나 위층 플랫폼이 남아 있으면 아래 플랫폼을 철거할 수 없습니다. 안전하게 철거하면 강철 보·모듈 프레임 전량과 코인 35%를 회수합니다.
- 채굴기·물 펌프·원유 펌프·반입 부두·반출 부두·전력 인입구는 지상 전용입니다. 나머지 지원되는 설비는 플랫폼 위에 놓을 수 있습니다.
- 같은 X/Z라도 층이 다르면 고체와 유체가 저절로 섞이지 않습니다. 전력도 같은 층에서 이어지고, 인접 층의 같은 X/Z에 세운 전신주 쌍만 수직으로 전력을 연결합니다.

`화물 승강기`는 고체, `유체 라이저`는 유체를 바로 위나 아래 인접 층으로 보냅니다. 한 번 배치하면 같은 좌표의 두 층에 송신·수신 끝점이 함께 생기며 두 끝점 비용을 모두 지불합니다. 송신 끝점은 평면 물류를 받아 수직으로 보내고, 수신 끝점은 새로 받은 물자를 다음 틱부터 정면으로 내보냅니다. 두 끝점 모두 전력과 가동 상태가 필요합니다.

## v0.9 조건 자동화

`산업 제어` 연구 뒤 제어할 설비를 선택하고 `설비 구성 → 자동 조건`을 엽니다. 규칙은 도시 공유 재고 또는 특정 설비의 입력·출력·운반 화물을 한 틱 시작 시점에 읽습니다.

- 비교: 선택 자원이 임계값 `이상` 또는 `이하`
- 동작: 조건이 참일 때 `가동 허용` 또는 `정지`
- 한 대상에 최대 4개, 한 공장에 최대 64개 규칙
- 첫 규칙을 저장할 때 해당 설비에 제어 장치 1개를 설치하며, 이후 수정·삭제에는 다시 들지 않음
- 규칙을 모두 삭제해도 하드웨어는 남고, 설비 철거 시 제어 장치 1개를 회수
- 모든 활성 규칙 중 하나라도 막으면 `자동 조건 대기`; 수동 `일시 정지`는 항상 별도로 유지되고 우선함

규칙은 재고·클록·필터·수동 정지 값을 직접 쓰거나 임의 코드를 실행하지 않습니다. 측정 원본이 사라지거나 잘못되면 안전하게 대상 가동을 막고, 원본이나 대상을 철거하면 관련 규칙을 함께 제거합니다.

## 도시 생산의 기본 흐름

모든 도시 생산 시설은 시청에서 이어진 도로에 인접해야 가동합니다. 물 위의 도로는 교량이 되며 주민과 경량 물류 설비도 이 교량을 이용합니다.

| 생산 시설 | 입력 | 출력·기능 |
|---|---|---|
| 벌목장 | 없음 | 목재 |
| 채석장 | 없음 | 석재 |
| 농장 | 없음 | 곡물 |
| 제분소 | 곡물, 동력 | 밀가루 |
| 제과점 | 밀가루, 동력 | 빵 |
| 광산 | 동력 | 광석 |
| 제련소 | 광석, 동력 | 강철 |
| 공방 | 강철 + 목재, 동력 | 도구 |
| 증기 동력소 | 목재 0.6×레벨/일 | 동력 18×레벨 |

풍차는 레벨당 동력 8을 공급합니다. 창고는 연결된 생산 시설의 효율을 높입니다. 산업 시대의 공급 차량은 도로 연결을 보여 주는 연출이며 차량별 적재와 도착은 재고에 영향을 주지 않습니다.

## 같은 도시에서 자동화하기

하단의 `설비`와 `물류` 탭은 같은 도시 필지 위에 산업 설비를 놓습니다. `설비 G` 버튼이나 데스크톱의 `G`는 두 탭을 열고 닫을 뿐 카메라나 화면을 전환하지 않습니다.

도시 필지 하나는 설비 격자의 2×2 미세 칸입니다. 2×2 설비는 필지 하나에 맞춰 놓이며, 1×1 경량 설비는 필지 안의 반쪽 간격을 사용합니다.

### 점진적 자동화 규칙

- 투입기가 없는 생산 시설은 기존처럼 도시 공유 재고에서 입력을 쓰고 출력도 공유 재고에 더합니다.
- 생산 시설을 투입기의 집는 쪽에 맞추면 이후 생산물이 그 시설의 `LogisticsOutput` 물리 버퍼로 들어갑니다. 농장과 벌목장 같은 원료 시설, 제분소·제과점·제련소·공방 같은 가공 시설에 같은 규칙이 적용됩니다.
- 가공 시설을 투입기의 놓는 쪽에 맞추면 도착한 원료가 `LogisticsInput` 물리 버퍼에 쌓입니다. 그 시설은 공유 재고 대신 이 버퍼를 소비합니다.
- 입력과 출력은 따로 자동화할 수 있습니다. 기존 도시에 벨트 구간을 하나씩 보태도 나머지 생산 흐름은 계속 작동합니다.
- 도시 시설의 물리 입력·출력 버퍼는 각각 전체 80개까지 보관합니다. 출력 버퍼가 가득 차면 원료를 소비하지 않고 생산이 대기합니다.
- 투입기 연결이 설정되면 그 경로가 물리 물류로 취급됩니다. 전력이 끊긴 투입기는 운반하지 못하므로 버퍼가 차고 생산이 멈출 수 있습니다.
- 벨트·분배기·투입기·설비 창고와 부두는 고체만 운반합니다. 유체를 이 경로에 넣을 수 없고 유체 부두 반출도 지원하지 않습니다.
- 물·석유·화학 유체는 생산 설비의 방향 포트와 파이프·분기점·유체 탱크를 연결해 운반합니다. 유체 설비는 한 종류만 담으며 다른 유체가 섞이는 연결을 거부합니다.

예를 들어 농장의 미세 칸을 투입기의 뒤쪽에 맞추고, 투입기 앞에 벨트를 놓으면 곡물이 실제 물체로 나옵니다. 벨트 끝 투입기의 앞쪽을 제분소 필지에 맞추면 곡물이 제분소 입력 버퍼에 들어갑니다. 제분소의 다른 쪽에 출력 투입기를 붙이면 완성된 밀가루도 다음 공정으로 물리 이동합니다.

### 도시 물류 접점

- 도로망에 연결된 `시청`과 도시 `창고`는 실제 고체 물자를 공유 재고로 받으며, 투입기는 이곳에서 공유 재고의 고체를 꺼낼 수도 있습니다.
- 도로망에 연결된 `시장`은 빵과 도구만 받습니다.
- 연결된 `반출 부두`에 도착한 고체는 공유 재고와 반출 통계에 들어갑니다.
- 설비 `창고`와 `반입 부두`에는 고체를, `유체 탱크`에는 유체를 `설비 구성`에서 직접 넣을 수 있습니다.
- 연결이 끊긴 시청·도시 창고·시장과 도로에 닿지 않은 반출 부두는 도시 재고 인계를 거부합니다.

실제 고체는 벨트·분배기·투입기·설비 버퍼·도시 물류 버퍼에, 유체는 생산 설비·파이프·분기점·탱크에 계속 보존됩니다. 자세한 배치와 설비 규칙은 [공장 설계 가이드](FACTORY_GUIDE.ko.md)를 참고하세요.

## 배치와 점유

- 설비는 구매한 지역 안에만 놓을 수 있습니다.
- 채굴기는 선택한 철·구리·석탄·보크사이트 광상이 2×2 범위에 있어야 하고, 원유 펌프는 유전, 물 펌프는 비어 있는 수면에 맞춰야 합니다.
- 일반 기계, 설비 창고, 부두, 전력 인입구와 유체 탱크는 물 위에 놓을 수 없습니다.
- 벨트·투입기·전신주·분배기는 도시 도로와 같은 필지에 놓을 수 있습니다. 물에서는 도로 교량이 먼저 필요합니다. 파이프와 파이프 분기점은 구매한 수면도 통과할 수 있습니다.
- 도시 건물이 있는 필지는 설비를 막습니다. 설비가 차지한 필지에도 도시 건물을 지을 수 없습니다.
- 기계가 차지한 필지에는 도로를 놓을 수 없습니다. 경량 물류 설비와 도로는 겹쳐 사용할 수 있습니다.
- 물 위에 벨트·투입기·전신주·분배기가 남아 있으면 그 아래 도로 교량을 먼저 철거할 수 없습니다. 파이프와 분기점은 교량 없이 수면을 통과합니다.

배치 실패 시 비용은 빠지지 않습니다. 설비를 철거하면 입력·출력·운반 중 물자를 도시 재고로 회수하고 건설비의 코인·목재·석재를 각각 35% 돌려받습니다.

## 설비 선택과 구성

설비를 클릭하면 오른쪽 도시 검사기에 미세 좌표, 방향, 크기, 전력, 입출력, 화물·유체·공정 진행률과 상태가 표시됩니다. `설비 구성`을 누르면 도시가 뒤에 보이는 창이 열립니다.

- 생산 설비: 호환 제조법 선택. 잠긴 제조법은 필요한 연구와 함께 표시
- 투입기: `모든 물자` 또는 특정 고체 필터 선택
- 파이프·분기점·유체 탱크: 자동 또는 특정 유체 필터 선택
- 설비 창고·반입 부두: 고체 수동 투입, 유체 탱크: 유체 수동 투입
- 생산 설비: 일시 정지와 50%·100%·150%·200% 클록 설정
- 모든 버퍼 보유 설비: `재고 회수`로 입력·출력·운반 물자를 도시 재고에 반환
- `조건 자동화`: 산업 제어 연구 후 재고 기준 가동 규칙 설정
- `산업 도감`: 37개 제조법과 38개 자원, 생산 사슬 열기
- `닫기`: 구성 창을 닫고 같은 도시로 복귀

제조법을 바꾸면 호환성과 기술을 먼저 확인한 뒤 기존 입력·출력 고체와 유체를 도시 재고로 회수하고 진행률을 0으로 초기화합니다. 실패하면 기존 제조법과 재고가 그대로 남습니다. 50%와 100%는 기본 사용 가능하고 150%와 200%는 `고급 제조`가 필요합니다. 생산 속도는 클록 비율에 비례하지만 전력 수요는 비율의 제곱이므로 150%는 2.25배, 200%는 4배 전력을 요구합니다.

## 주민 생활과 경제

인구 한 명마다 플레이 중 유지되는 고유 이름과 집이 있습니다. 연결 가능한 일자리와 시장 또는 공원이 있으면 `집 → 직장 → 시장/공원 → 집` 순서로 실제 도로를 걷고, 일하거나 쉬는 동안에는 건물 안에 머뭅니다. 도로·건물 철거, 새 도로 건설, 불러오기 뒤에는 목적지와 경로를 다시 계산합니다.

거리 혼잡을 막기 위해 최대 128명만 밖에서 움직이며 나머지는 집 안에 있습니다. 이 제한은 실제 인구나 경제 계산을 줄이지 않습니다. 주민 소비와 세금은 도시 경제에서 한 번만 계산되며 개별 주민 이동이 재고를 추가로 소비하거나 생산하지 않습니다. 기본 행동은 로컬 일과이며, 선택형 주민 AI를 연결하면 검증된 OpenRouter 계획만 실제 도로 경로에 적용합니다. 연결이나 응답이 실패하면 로컬 일과를 계속합니다.

- 주택은 레벨당 주민 6명을 수용합니다. `석조술` 후 레벨 2, `도시 계획` 후 레벨 3으로 증축할 수 있습니다.
- 빵이 부족하면 곡물 2개로 빵 1개분의 식사를 대신합니다. 곡물도 부족하면 성장 중단, 행복 하락, 심한 경우 인구 감소가 일어납니다.
- 시장은 빵 재고가 낮을 때 코인으로 기초 식량을 자동 수입합니다.
- 인구 24명부터 도구를 선택적 생활 편의로 소비합니다. 부족해도 주택 성장이 직접 멈추지는 않습니다.
- 긴급 교역은 10개 단위입니다. 하단 `교역` 창에서 PC와 모바일 모두 명시적인 구매·판매 버튼을 사용합니다.
- 추가 지역 가격은 `320 + 140 × 이미 소유한 추가 지역 수` 코인입니다.

## 목표 순서

1. 시청에 건물 12개 연결
2. 인구 16명과 빵 4개 확보
3. 인접 지역 1곳 구매
4. 인구 30명, 가동한 연결 광산·제련소·공방, 실제 광석·강철·도구 생산과 도구 반출 달성
5. `도시 계획` 연구, 인구 45명, 소유 지역 4곳 달성

교역으로 산 도구는 실제 생산 실적에 포함되지 않습니다.

`산업 도감`에는 제어 장치 3개를 실제 생산·반출하는 선택 목표도 있습니다. 이 목표는 복합 산업망의 상태를 보여 주는 지표이며 코인·인구·승리 상태를 직접 바꾸지 않습니다.

| `R` | 설비 도구 또는 선택 설비 회전, 설비 선택이 없으면 도로 도구 |
| `H` | 주택 도구 |
| `T` | 기술 연구 창 열기·닫기 |
| `Delete` | 현재 선택 종류의 철거 모드 |
| `Esc` | 열린 창 또는 도구 닫기 |
| `1` / `2` / `3` | 정지 / 1배속 / 3배속 |
| `Space` | 일시정지 전환 |
| `F5` | 즉시 저장 |
| `M` | 소리 켜기·끄기 |
| `F1` | 게임 내 도움말 |

Android에서는 같은 HUD의 `설비`·`물류`, `회전`, `철거`, `취소`, 속도와 구성 버튼을 사용합니다. 짧게 탭하면 배치하거나 선택합니다. 배치·철거 도구가 없을 때 한 손가락 드래그로 카메라를 이동하고, 두 손가락 드래그와 핀치로 도구 선택 여부와 관계없이 이동·확대합니다. 시스템 뒤로 가기는 현재 도구나 열린 팔레트·창을 순서대로 닫습니다. 별도 공장 카메라는 없습니다.

기본 속도에서는 현실 5초가 게임 하루입니다. 도움말, 새 도시 확인, 연구 또는 설비 구성 창이 열리면 날짜, 주민과 설비 시뮬레이션이 멈춥니다.

## 저장과 기존 도시

도시 프로젝트, 플랫폼, 층간 링크와 자동화 규칙까지 도시 저장 버전 **v6**, 공장 상태 버전 **v3**의 같은 파일에 기록됩니다.

```text
%USERPROFILE%\AppData\LocalLow\Riverworks Studio\Riverworks\city-v1.json
```

v3 도시를 처음 불러오면 예전 24×16 공장 상태를 `ArchivedFactory`에 원본 그대로 보관하고, 실제로 작동하는 `Factory`는 빈 42×42 공유 도시 격자로 시작합니다. 옛 설비의 입력·출력·운반 중 물자와 회수 대기 물자는 도시 재고로 한 번 반환되며 코인·목재·석재 건설비도 전액 한 번 환급됩니다. 누적 생산·반출 기록은 이어집니다.

보관된 옛 배치는 기록용입니다. 선택하거나 다시 실행할 수 없고, 도시 위에 자동 배치되거나 두 번째로 반출되지 않습니다. v1~v4 도시는 먼저 기존 9칸 형식을 검증해 v5·공장 v2로 만들고, 그 상태를 다시 검증한 뒤 v6·공장 v3으로 올립니다. 기존 설비는 지상에 남고 수동 일시 정지·재고·진행률을 보존합니다. 플랫폼·층간 링크·제어 하드웨어·자동화 규칙·도시 프로젝트는 자동 지급하지 않습니다. 현재 v6의 잘못된 층·링크·지지·규칙·프로젝트 상태는 임의로 고치지 않고 불러오기를 거부합니다.

게임은 약 90초마다, 백그라운드 전환과 정상 종료, `F5` 입력 시 저장합니다. 저장 교체 시 `city-v1.json.bak`을 만들고, `새 도시`는 현재 도시를 `city-v1.json.previous-city.json`에 먼저 보관합니다.
