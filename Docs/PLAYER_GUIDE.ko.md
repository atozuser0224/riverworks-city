# RIVERWORKS 플레이어 가이드

## 목표

중세 정착지에서 도로와 생산 시설을 연결하고 지식을 모아 기술을 연구하세요. 대도시로 가는 핵심 기술 9종과 생산·물류를 강화하는 선택 기술 9종, 모두 18종이 있습니다. 르네상스와 산업 시대로 발전해 광산·제련소·공방과 실제 물류망을 완성하고, 인구 45명·지역 4곳·`도시 계획` 연구를 달성하면 대도시가 됩니다.

RIVERWORKS v0.5에서는 도시 건물과 산업 설비를 같은 지도에 놓고 작은 도구 막대로 조작합니다. 주민과 움직이는 물자도 한 카메라에서 함께 보입니다.

## 작은 UI 사용하기

- 하단의 건설 분류를 누르면 목록이 펼쳐집니다. 같은 분류를 다시 누르거나 `도구` 버튼을 누르면 접습니다.
- 건설 도구를 고르면 목록이 접히고 현재 도구·취소·회전만 작은 막대에 표시됩니다.
- 건물·설비·주민을 선택했을 때만 오른쪽 정보가 열립니다. `닫기`는 선택도 해제합니다.
- 왼쪽의 목표 요약을 누르면 상세 목표를 펼칩니다.
- 하단 `현황`, `영토`, `교역`으로 도시 통계·지역 구매·10개 단위 구매 및 판매 창을 엽니다.
- `메뉴`에서 저장·불러오기·새 도시·도움말을 사용할 수 있습니다. 기존 단축키도 그대로 동작합니다.

## 처음 시작하기

새 도시는 중앙 5번 지역의 중세 마을입니다. 시청은 `(10, 10)`, 주택은 `(9, 9)`와 `(11, 9)`, 농장은 `(9, 8)`에 있습니다. 짧은 십자형 도로는 시청에서 `(10, 8)`, `(8, 10)`, `(12, 10)`까지 이어집니다.

1. `(7, 10)`의 숲에 `벌목장`을 지으세요. 시작 도로 끝에 바로 연결됩니다.
2. `석조술`을 연구한 뒤 `(13, 10)`의 바위 근처에 `채석장`을 지으세요.
3. `(11, 8)` 같은 도로 옆 빈 평지에 `서재`를 지어 연구 속도를 높이세요. 이미 사용 중이면 같은 도로에 인접한 조건 맞는 빈 필지를 사용합니다.
4. `T`로 연구 창을 열어 `윤작`을 시작하세요. 연구 창이 열린 동안 도시는 멈추고, 연구 시작 버튼을 누르면 창이 닫혀 날짜가 다시 흐릅니다.
5. 초반에는 농장의 곡물로 주민을 먹일 수 있습니다. 곡물 식사는 빵보다 행복과 성장 효과가 낮으므로 `윤작 → 기계 동력` 뒤 풍차·제분소·제과점을 연결하세요.
6. 자동화는 나중에 조금씩 추가해도 됩니다. 투입기가 없는 생산 시설은 기존 도시 공유 재고를 계속 사용합니다.

좌표와 지형은 필지를 선택한 뒤 오른쪽 검사기에서 확인합니다.

## 기술과 시대

지식은 매일 `0.8 + 주민 수×0.04`만큼 쌓입니다. 연결된 `서재`는 레벨당 1.5, `학술원`은 레벨당 3.5를 추가합니다. `교육`을 연구하면 서재의 기여량이 레벨당 2.5로 늘어납니다. 연구 시작 때 지식과 코인을 한 번 지불하고 표시된 날짜가 지나면 완료됩니다. 동시에 하나만 연구할 수 있습니다.

## 도시 생산의 기본 흐름

모든 도시 생산 시설은 시청에서 이어진 도로에 인접해야 가동합니다. 물 위의 도로는 교량이 되며 주민과 경량 물류 설비도 이 교량을 이용합니다.

| 생산 시설 | 입력 | 출력·기능 |
|---|---|---|
| 벌목장 | 없음 | 목재 |
| 채석장 | 없음 | 석재 |
| 농장 | 없음 | 곡물 |
| 제분소 | 곡물, 동력 | 밀가루 |
| 제과점 | 밀가루, 동력 | 빵 |
| 광산 | 동력 | 광석 |
| 제련소 | 광석, 동력 | 강철 |
| 공방 | 강철 + 목재, 동력 | 도구 |
| 증기 동력소 | 목재 0.6×레벨/일 | 동력 18×레벨 |

풍차는 레벨당 동력 8을 공급합니다. 창고는 연결된 생산 시설의 효율을 높입니다. 산업 시대의 공급 차량은 도로 연결을 보여 주는 연출이며 차량별 적재와 도착은 재고에 영향을 주지 않습니다.

## 같은 도시에서 자동화하기

하단의 `설비`와 `물류` 탭은 같은 도시 필지 위에 산업 설비를 놓습니다. `설비 G` 버튼이나 데스크톱의 `G`는 두 탭을 열고 닫을 뿐 카메라나 화면을 전환하지 않습니다.

도시 필지 하나는 설비 격자의 2×2 미세 칸입니다. 2×2 설비는 필지 하나에 맞춰 놓이며, 1×1 경량 설비는 필지 안의 반쪽 간격을 사용합니다.

### 점진적 자동화 규칙

- 투입기가 없는 생산 시설은 기존처럼 도시 공유 재고에서 입력을 쓰고 출력도 공유 재고에 더합니다.
- 생산 시설을 투입기의 집는 쪽에 맞추면 이후 생산물이 그 시설의 `LogisticsOutput` 물리 버퍼로 들어갑니다. 농장과 벌목장 같은 원료 시설, 제분소·제과점·제련소·공방 같은 가공 시설에 같은 규칙이 적용됩니다.
- 가공 시설을 투입기의 놓는 쪽에 맞추면 도착한 원료가 `LogisticsInput` 물리 버퍼에 쌓입니다. 그 시설은 공유 재고 대신 이 버퍼를 소비합니다.
- 입력과 출력은 따로 자동화할 수 있습니다. 기존 도시에 벨트 구간을 하나씩 보태도 나머지 생산 흐름은 계속 작동합니다.
- 도시 시설의 물리 입력·출력 버퍼는 각각 전체 80개까지 보관합니다. 출력 버퍼가 가득 차면 원료를 소비하지 않고 생산이 대기합니다.
- 투입기 연결이 설정되면 그 경로가 물리 물류로 취급됩니다. 전력이 끊긴 투입기는 운반하지 못하므로 버퍼가 차고 생산이 멈출 수 있습니다.

예를 들어 농장의 미세 칸을 투입기의 뒤쪽에 맞추고, 투입기 앞에 벨트를 놓으면 곡물이 실제 물체로 나옵니다. 벨트 끝 투입기의 앞쪽을 제분소 필지에 맞추면 곡물이 제분소 입력 버퍼에 들어갑니다. 제분소의 다른 쪽에 출력 투입기를 붙이면 완성된 밀가루도 다음 공정으로 물리 이동합니다.

### 도시 물류 접점

- 도로망에 연결된 `시청`과 도시 `창고`는 실제 물자를 공유 재고로 받으며, 투입기는 이곳에서 공유 재고의 물자를 꺼낼 수도 있습니다.
- 도로망에 연결된 `시장`은 빵과 도구만 받습니다.
- 연결된 `반출 부두`에 도착한 물자는 공유 재고와 반출 통계에 들어갑니다.
- 설비 `창고`와 `반입 부두`를 선택한 뒤 `설비 구성`에서 도시 재고를 10개씩 직접 넣을 수 있습니다.
- 연결이 끊긴 시청·도시 창고·시장과 도로에 닿지 않은 반출 부두는 도시 재고 인계를 거부합니다.

실제 물자는 벨트, 분배기, 투입기, 설비 입력·출력, 도시 물류 버퍼 중 한 곳에 계속 보존됩니다. 자세한 배치와 설비 규칙은 [공장 설계 가이드](FACTORY_GUIDE.ko.md)를 참고하세요.

## 배치와 점유

- 설비는 구매한 지역 안에만 놓을 수 있습니다.
- 채굴기는 2×2 범위 중 하나 이상이 도시의 실제 바위 지형과 겹쳐야 합니다. 별도 공장용 고정 광맥은 없습니다.
- 기계, 설비 창고, 부두, 전력 인입구는 물 위에 놓을 수 없습니다.
- 벨트·투입기·전신주·분배기는 도시 도로와 같은 필지에 놓을 수 있습니다. 물에서는 도로 교량이 먼저 필요합니다.
- 도시 건물이 있는 필지는 설비를 막습니다. 설비가 차지한 필지에도 도시 건물을 지을 수 없습니다.
- 기계가 차지한 필지에는 도로를 놓을 수 없습니다. 경량 물류 설비와 도로는 겹쳐 사용할 수 있습니다.
- 물 위 경량 설비가 남아 있으면 그 아래 도로 교량을 먼저 철거할 수 없습니다.

배치 실패 시 비용은 빠지지 않습니다. 설비를 철거하면 입력·출력·운반 중 물자를 도시 재고로 회수하고 건설비의 코인·목재·석재를 각각 35% 돌려받습니다.

## 설비 선택과 구성

설비를 클릭하면 오른쪽 도시 검사기에 미세 좌표, 방향, 크기, 전력, 입출력, 화물·공정 진행률과 상태가 표시됩니다. `설비 구성`을 누르면 도시가 뒤에 보이는 작은 창이 열립니다.

- 용광로와 조립기: 제조법 선택
- 투입기: `모든 물자` 또는 특정 자원 필터 선택
- 설비 창고와 반입 부두: 도시 재고에서 선택한 물자 10개 투입
- `닫기`: 구성 창을 닫고 같은 도시로 복귀

제조법을 바꾸면 기존 입력·출력 물자는 도시 재고로 회수되고 진행률은 0으로 초기화됩니다. 운반 중인 물자가 있는 설비는 물자를 내려놓기 전까지 회전할 수 없습니다.

## 주민 생활과 경제

인구 한 명마다 플레이 중 유지되는 고유 이름과 집이 있습니다. 연결 가능한 일자리와 시장 또는 공원이 있으면 `집 → 직장 → 시장/공원 → 집` 순서로 실제 도로를 걷고, 일하거나 쉬는 동안에는 건물 안에 머뭅니다. 도로·건물 철거, 새 도로 건설, 불러오기 뒤에는 목적지와 경로를 다시 계산합니다.

거리 혼잡을 막기 위해 최대 128명만 밖에서 움직이며 나머지는 집 안에 있습니다. 이 제한은 실제 인구나 경제 계산을 줄이지 않습니다. 주민 소비와 세금은 도시 경제에서 한 번만 계산되며 개별 주민 이동이 재고를 추가로 소비하거나 생산하지 않습니다. 주민 행동은 로컬 규칙만 사용하며 LLM이나 외부 AI 서비스에 연결되지 않습니다.

- 주택은 레벨당 주민 6명을 수용합니다. `석조술` 후 레벨 2, `도시 계획` 후 레벨 3으로 증축할 수 있습니다.
- 빵이 부족하면 곡물 2개로 빵 1개분의 식사를 대신합니다. 곡물도 부족하면 성장 중단, 행복 하락, 심한 경우 인구 감소가 일어납니다.
- 시장은 빵 재고가 낮을 때 코인으로 기초 식량을 자동 수입합니다.
- 인구 24명부터 도구를 선택적 생활 편의로 소비합니다. 부족해도 주택 성장이 직접 멈추지는 않습니다.
- 긴급 교역은 10개 단위입니다. 하단 `교역` 창에서 PC와 모바일 모두 명시적인 구매·판매 버튼을 사용합니다.
- 추가 지역 가격은 `320 + 140 × 이미 소유한 추가 지역 수` 코인입니다.

## 목표 순서

1. 시청에 건물 12개 연결
2. 인구 16명과 빵 4개 확보
3. 인접 지역 1곳 구매
4. 인구 30명, 가동한 연결 광산·제련소·공방, 실제 광석·강철·도구 생산과 도구 반출 달성
5. `도시 계획` 연구, 인구 45명, 소유 지역 4곳 달성

교역으로 산 도구는 실제 생산 실적에 포함되지 않습니다.

## 조작

Android에서는 같은 HUD의 `설비`·`물류`, `회전`, `철거`, `취소`, 속도와 구성 버튼을 사용합니다. 짧게 탭하면 배치하거나 선택합니다. 배치·철거 도구가 없을 때 한 손가락 드래그로 카메라를 이동하고, 두 손가락 드래그와 핀치로 도구 선택 여부와 관계없이 이동·확대합니다. 시스템 뒤로 가기는 현재 도구나 열린 팔레트·창을 순서대로 닫습니다. 별도 공장 카메라는 없습니다.

기본 속도에서는 현실 5초가 게임 하루입니다. 도움말, 새 도시 확인, 연구 또는 설비 구성 창이 열리면 날짜, 주민과 설비 시뮬레이션이 멈춥니다.

## 저장과 기존 도시

도시와 설비 배치는 저장 버전 **v4**의 같은 파일에 기록됩니다.

```text
%USERPROFILE%\AppData\LocalLow\Riverworks Studio\Riverworks\city-v1.json
```

v3 도시를 처음 불러오면 예전 24×16 공장 상태를 `ArchivedFactory`에 원본 그대로 보관하고, 실제로 작동하는 `Factory`는 빈 42×42 공유 도시 격자로 시작합니다. 옛 설비의 입력·출력·운반 중 물자와 회수 대기 물자는 도시 재고로 한 번 반환되며 코인·목재·석재 건설비도 전액 한 번 환급됩니다. 누적 생산·반출 기록은 이어집니다.

보관된 옛 배치는 기록용입니다. 선택하거나 다시 실행할 수 없고, 도시 위에 자동 배치되거나 두 번째로 반출되지 않습니다. v1과 v2 저장은 기존 호환 변환을 먼저 거친 뒤 같은 v4 변환을 적용합니다.

게임은 약 90초마다, 백그라운드 전환과 정상 종료, `F5` 입력 시 저장합니다. 저장 교체 시 `city-v1.json.bak`을 만들고, `새 도시`는 현재 도시를 `city-v1.json.previous-city.json`에 먼저 보관합니다.
