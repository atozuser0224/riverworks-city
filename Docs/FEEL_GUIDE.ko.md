# Feel 연출 안내

제공된 Feel 5.6.1의 실제 `MMF_Player`와 스케일·위치·색·투명도·파티클 피드백을 게임에 연결했습니다.

- 버튼: 가벼운 확대, 눌림, 놓을 때 탄성, 선택 불가 반응
- 창: 목표·선택 정보·도구 목록·연구·메뉴가 나타나는 애니메이션
- 자원: 실제 표시 수치가 늘었을 때만 짧게 강조
- 도시: 건설 착지, 증축 반동, 철거 먼지, 영토 확장 표시
- 설비: 설치·철거·제조법 변경·수동 물자 투입 반응
- 성장: 연구 완료·시대 발전·도시 목표 달성 연출
- 시작: 새 도시의 시청이 내려와 자리 잡는 도착 연출
- 카메라: 시청을 가까이 당겼다가 돌아오는 줌, 단우 추적, 건설·연구 완료의 짧은 줌 반응

`메뉴 → 화면 효과`에서 풍부한 효과와 절제된 효과를 전환합니다. 절제된 효과는 큰 움직임과 카메라 반동을 줄이고 색·투명도 중심으로 알려줍니다. UI 애니메이션은 도시가 일시정지되어 있어도 작동합니다.

연출은 도시의 자원·생산·건설 판정과 분리되어 있습니다. 지면 선택용 콜라이더는 움직이지 않으며, 같은 효과를 연속 재생하거나 대상을 철거·교체하면 기존 애니메이션을 정리하고 위치·크기를 복원합니다.

카메라를 직접 움직이면 진행 중인 자동 이동·줌을 중단하고 현재 보이는 구도를 이어받습니다. 수동 조작 직후에는 자동 반응을 잠시 억제합니다. 단우 추적도 자동으로 다시 붙지 않으며 새 대화나 `단우 보기`로 다시 시작합니다.

제공된 패키지에서 게임에 필요한 피드백·도구를 가져왔으며 원본 데모와 NiceVibrations 네이티브 플러그인은 실행에 포함하지 않았습니다. Unity 6.5용 편집기 식별자 API와 현재 설치된 UI 어셈블리 참조를 조정했습니다. 원본 Feel 라이선스는 배포 폴더의 `FEEL-LICENSE.txt`에 포함합니다.
